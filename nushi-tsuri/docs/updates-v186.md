# v186 大会の音楽・順位演出

## 音楽

4曲を新規作曲し、ゲーム内で切り替える。既存の楽器合成処理を使ったオリジナル曲で、借用音源・外部サービス・追加の依存はない。

| 場面 | 曲 | BPM |
| --- | --- | --- |
| 星湖フナ大会 | 湖上の勝負・最後の一投 | 140 |
| 星湖名手挑戦 | 名手への挑戦・火花の水面 | 152 |
| なつき度・芸コンテスト受付と結果 | しっぽとリボンのワルツ | 108 |
| 魚の品評会受付と結果 | きらめく鱗の宝石箱 | 92 |

釣り大会中は移動・仕掛け・待ち・魚との勝負・結果まで専用曲が続く。通常の釣りは従来どおり水の音。ペットショップはコンテスト受付の種目で曲を選び、売り場や水槽へ戻ると元の場面の音に戻る。音量設定、バックグラウンド停止、再開、遅延読込のキャンセルは既存の単一音楽プレイヤーを共用する。水中音・巻き音などは残す。

## 順位の舞台

釣り大会、なつき度コンテスト、芸コンテスト、魚の品評会にそれぞれ別のドット絵の舞台。釣り竿と水面、ハートとリボン、輪と星、飼育水槽と泡を描き、既存の魚・シュウ／リク／Greyの絵を動かす。魚種と出場したワンコの姿を保持する。

1位は金のトロフィーと大きなジャンプ、2位は銀メダルと二段ステップ、3位は銅メダルとお辞儀・穏やかな泳ぎ。4位・5位には別の色と小さな動きで次の挑戦を応援する。同率は同率と表示。途中終了・療養は参考順位とおつかれさまの演出にし、優勝扱いにしない。

演出は結果の一部で、閉じるボタンを塞がず、待ち時間も追加しない。再描画や再表示は抽選・採点・支払いを行わない。動きを減らす設定では静止画、非表示・終了時はアニメーション停止。スマホでも結果文と並べ、狭い画面では縦に配置する。

新しいコンテスト結果には表示用の `subject`（犬IDまたは魚種ID）を追加。過去の結果は、既知の名前に一致する場合にその絵を表示する。参加者を選び直しても前回の結果の絵は変わらない。魚・成長・所持金・水槽・図鑑・大会記録は維持する。

## 名手の登場

リアオ・アスアル・ダンと、その相棒犬は名手挑戦に参加中から結果を閉じるまで湖に集まる。日常や通常のフナ大会には集まらず、名手挑戦を終えると仕事へ戻る。旧保存データの大会後の集合も湖には表示しない。

アスアルは普段どおり水車の家の店主として利用できる。サムのチャッピーと、通常大会後の村人への挨拶は継続する。
