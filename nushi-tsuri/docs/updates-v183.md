# v183 季節の音楽と、みんなの水槽

## 季節のBGM

4つのマップ曲を新しいオリジナル曲へ差し替え。

| 季節 | 曲名 | 雰囲気 |
| --- | --- | --- |
| 春 | ひだまりの水辺 | 76 BPM。穏やかなピアノと爪弾く弦、明るくゆったり |
| 夏 | サンシャイン桟橋 | 104 BPM。スティールパン風の音、ウクレレ風の裏拍、軽い打楽器 |
| 秋 | 木の葉のステップ | 92 BPM。短い弦の音と控えめなリズム、歯切れのよい旋律 |
| 冬 | 雪明かりの毛布 | 68 BPM。柔らかな鍵盤と伴奏、澄んだベルの余韻 |

長調を中心に、曲ごとに和音・旋律・楽器・リズムを作曲。店舗や自宅はそれぞれの専用曲を使い、釣り中の環境音、音の切り替え、ミュートも継続する。

## ワンコの声

ライバル犬のクーン声を0.68秒の短い合成音に作り直した。長い笛のような音程変化を抑え、息と鼻にかかる倍音を加えた。クーン声の再生速度は0.94〜1.04倍に収め、音程を維持する。通常の吠え声と個々のアクションは継続する。

## 1槽5匹の持ち歩き飼育水槽

- 6槽それぞれに5匹、合計30匹まで飼育できる。
- お店の「迎える水槽」で行き先を選べる。淡水魚と海水魚は別の水槽へ。
- 飼育画面の「水槽」で切り替え、「様子を見る魚」で1匹ずつ体長・成長・元気を確認。
- 「この魚を移す」で空きのある同じ水の水槽へ移動できる。
- 普通の魚は「アスアルに託す」から対象を確認して手放せる。全30匹まで埋めても空きを作り、新しい魚や後から釣ったヌシを迎えられる。返金はなく、一度限りのヌシは対象外。
- 「みんなにエサ」は、その日まだ食べていない魚に1食ずつ。必要数に足りない場合は消費しない。
- 水換えはその水槽全体に適用。購入・移動で水質や給餌の記録をリセットしない。
- 従来どおり、水質40%以上で給餌した翌日に1匹ずつ0.10cm成長。日を飛ばしても1食で何日分も育つことはない。

旧版の6匹は、それまでの個別水槽に残したまま移行する。好きな組み合わせにしたい場合は「この魚を移す」を使う。体長、給餌日、犬の好感度、コンテスト記録も引き継ぐ。

## 水の中の見た目と食事音

共通の体長縮尺と目盛りを導入。大きな魚種には広い水槽を割り当て、魚の成長中は縮尺が急に変わらないようにした。画面上の最小表示幅は8pxで、小さな魚も見失いにくくしている。

泳ぐ高さ・速さ・奥行きを分け、底にいる魚は低い位置で泳ぐ。水面の光、ガラスの反射、砂利、岩、水草、気泡、水質に応じた薄い濁りを追加。ズームでも水槽全体と5匹の関係を確認できる。

エサの粒に魚が近づき、食べるタイミングで小さな水音が鳴る。閉じたときやバックグラウンドでは動きと食事音を停止。音OFFでも飼育は進み、「動きを減らす」設定では泳ぎを止めて結果を表示する。
