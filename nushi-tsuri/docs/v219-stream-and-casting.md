# v219 渓流の魚と釣りの準備画面

葦の沼でキャスト準備画面を開くと星降る湖の背景が出ていた。絵の選択が水域の大分類（湖・川）を参照していたため、地域の名前と描画が一致しなかった。`mountainType` を優先し、渓流・池・沼・地下湖の四つの専用風景へ切り替える。峠の池と沼も対応する水辺の絵を使用する。村の湖・川、沿岸、サムの練習池は従来の絵を保つ。

背景原画 `assets/mountain-cast-v219.png` は1774×887の2×2アトラス。左上は岩場と滝の渓流、右上は静かな山の池、左下は葦と湿った岸辺の沼、右下は鍾乳石と青い結晶の地下湖。画像を塗り直したり縮小保存したりせず、共通コンポジタとWorkerが該当する区画を元解像度で取り出す。奇数サイズでも隣の区画が混入せず透明な端が出ないよう、共有境界を丸める。地下湖では屋外の星を出さない。浮きの軌道もそれぞれの開けた水面へ合わせた。

キャスト時の仕掛け画面は「釣り方／餌／ハリ／釣り竿／ファイト方式」の五つの切替に整理。閉じる・現在の装備・「この仕掛けで釣る」は固定し、分類と選択肢を別々にスクロールできる。選択した分類とキーボードの焦点は装備の更新後も保持。餌と時間の消費は従来どおり実際の投擲時だけ。ルアーロッドとスプーンの所持条件、秘餌のハリ大制限、竿の重複処理、ゲージ式・ぬし釣り式も継続する。

| 図鑑 | 魚 | 主な狙い方（ゲームの設定） |
| --- | --- | --- |
| 025 | イワナ | 星見渓流の川、ミミズ・ハリ中、浅瀬から深場 |
| 026 | アマゴ | 星見渓流の川、川虫・ハリ小、中層寄り。バッタやスプーンも有効 |
| 027 | カジカ | 星見渓流の川、川虫・ハリ小、深場寄り。ミミズでも釣れる |

二種は新たな解放条件を付けず川の三深度へ追加。アマゴは赤い朱点とパーマーク、カジカは幅広い頭と扇形の胸びれを持つ専用原画。魚図鑑、ファイト、六段階のサイズ、釣果記録、育成・水槽・繁殖カタログ、料理の魚素材、セーブへ接続する。渓流のヌシを解放する従来九種の条件は増やさない。

イワナは七つの方向から25の原画方向へ増やした。原画の切替時に口の画像内座標が変わり、口元を固定すると体の位置が飛んでいた。口は固定したまま胴体・びれの端の位置を補間する。全体を透明に重ねて二重の顔を作る処理は使用しない。448×224の97段階で測定した体の横中心の最大変化は、v218の49.5pxから7.5pxへ減少した。新三種は全段階で体とびれが欠けず、正面の厚みと左向きまでの連続性を保つ。

原画は組み込みの `image_gen` を使用した透明PNG。魚三種は25方向＋開口の26コマを実際のalpha輪郭で測定し、専用の切り出し矩形と口座標を `fish-art.js` に登録。イワナ・アマゴでは既存のスズキ25方向原画を配置の参考にし、魚の識別色・斑点・ひれを指定。カジカは褐色の斑模様、無鱗、丸く広い頭、扇形の胸びれを指定した。背景は既存の四つの山地域原画を参照し、地上の岸から水面を見る構図、手前の岸・中央の開けた水面・奥の景観、人物とUIを描かない条件を指定。納品原画:
