# v232 お店と道具袋を一画面で使う

水槽で使いやすくなった、主役を残して説明を必要なときに開く配置を、お店と道具袋へ広げる。

- サムの釣具店は六つの売り場を一列にまとめる。購入数量と合計価格は普段の画面に残す。大会・試し釣り・会話・物語は「案内」から開く。
- 八百屋・食堂は品物、奉納品、料理、作り置きを切り替え、数量や支払いを見ながら操作する。舟具屋では購入済みの舟を装備する操作も区別して表示する。
- 道具袋は九つの分類を横に並べ、品物を絵付きのカードで見せる。装備とタックルは種類ごとに切り替える。
- アスアルの店は魚・用品のカードと購入先の水槽を同じ画面に置く。買い取りは水槽、一匹、確定の手順を保つ。

一覧は画面の広さに合わせてページを切り替える。詳しい用途、注意、案内はパネル内で読む。通常の画面全体を下までスクロールして操作を探す必要を減らす。

カードの操作には元の購入・使用・装備ボタンを使う。支払い、数量、共有の食材、所持品の重複防止、料理の消費、竿の重ね、セーブ形式の処理を分けて書き直さない。説明を閉じると開いたボタンへ戻り、背景の操作を止めたままパネル内でTab移動できる。

神社のカプセル演出とコンテストの進行画面は、専用のゲーム演出として保つ。

確認はDOMでの閲覧・数量・支払い・一回の消費・装備・保存と、実ブラウザでのPC1280×720、横画面844×390、820×366（DPR1.875）で行う。ページ切り替えも実際のボタンを押し、画面の外やカードの外にはみ出す操作、44pxより小さい操作、通常画面の縦スクロールを検出する。最終結果はPRの検証欄へ記録する。
