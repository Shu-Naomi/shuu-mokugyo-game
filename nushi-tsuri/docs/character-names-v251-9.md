# 名前とお気に入り犬 — v251-9

基点main: `eaa9f074aa00e4c4a3b7abca34a4d687fcaff1c0`。既存オプションの主人公名変更を再利用し、3匹の表示名とお気に入り変更を追加した。フィールドメニュー→オプションから操作でき、主人公宅でも同じメニューを利用できる。タイトルの既存オプションでは選択中の既存セーブだけを変更する。今回、新しいタイトルや初回作成画面は追加しない。

名前は1〜12書記素（日本語・結合文字・絵文字を含む）。前後の空白を除きNFCへ正規化し、制御文字・方向制御・不可視の区切りを除く。空欄・不可視のみ・13文字以上は案内を出して変更しない。同名は許可。IME変換中のEnterでは保存しない。未送信の入力は閉じると破棄。入力は文字として表示し、HTMLとして解釈しない。各操作は保存成功後に画面へ反映し、保存失敗時はメモリの変更も戻す。

保存項目は既存の `playerName`、`avatar`、`dog` と、追加の `dogNames: {shuu,riku,grey}`。冒険JSONの任意項目の追加であり、別キーの端末共通設定には入れない。`petLife.version=6`・`mapVersion`・既存セーブキーは変更しない。旧データで名前がなければ主人公「旅人」、犬は「シュウ」「リク」「Grey」。タイトルの読み取りでは旧JSONを書き換えない。性別は既存どおり `boy` / `girl` で、その冒険では固定する。

犬の内部ID `shuu` / `riku` / `grey` は表示名から生成・推定せず、懐き度・芸・性格・追従・イベント・画像選択のキーも維持する。お気に入りは既存の `s.dog`（連れ歩く対象）を再利用する。設定画面で変更しても `dogFollowing` は変えず、お留守番中は継続する。既存の「この子と釣りへ行く」は従来どおり同行を開始する。名前やお気に入りは各セーブ内で独立し、もう一方の冒険や進行を変更しない。

犬のプロフィールの名前は現在のセーブから読み出す表示用アクセサーにして、会話・世話・採集・救援・同行・釣果の思い出へ反映する。コンテストの選択肢も現在名を読み、参加中・結果は保存済みの個体IDから表示名を求める。得点・抽選値・賞金や、保存済みの当時の名前は書き換えない。個体IDがない古い結果と過去のログ本文は、当時の文字列を残す。ライバルの犬には影響しない。
