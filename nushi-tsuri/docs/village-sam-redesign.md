# サムショップと港へ続く道：村の景観改修①

`village-layout-audit-v251.md` を起点に、今回の範囲をサムショップと店先だけに区切った。宿・魚屋の外観、田園と残り5マップの実装は `village-expansion-roadmap.md` に引き継ぐ。

## 場所を変えず、長く使われた釣具屋へ

使い込んだ瓦と木部、古い魚印のSAM看板、色褪せた藍の庇、軒下の竿立て、餌箱、桶、鉢植えを一つの店区画として描いた。祖父と主人公が以前から通っていた店として、中央階段と店前の擦れた石を残す。

村の北側の道から来て、店を経由して港・練習池へ抜ける既存配置を継続する。魚屋東の石畳、海際の通路と桟橋への接続を道具で塞がない。

原画 `assets/village-sam-v251-3.png` は内蔵image_genの編集で作成した未加工PNG。1407×1118、2546946bytes、SHA256 `88d868055afb912bc4054cbc286e9d774891225b5086a411ae70d294acf6b372`。元村1536×864の[1120,412,272,216]の区画を参照し、ゲーム内では[1120,405,272,216]へ置く。7pxの高さ調整で、新しい石段と道具の足元を元の入口・通路へ合わせる。制作プロンプトの全文は `art-prompts-village-sam.json`。

原画全体を村の背景に置き換えず、`scene-layers.js` に記録した店区画の輪郭だけを元の村へ合成してから、従来どおり部品分割・季節・時刻・天気の色調処理を行う。Workerにも同じ合成済み画素を渡す。元の村の画像は保持し、店区画外の画素差は0。これにより宿・魚屋・神社・水辺・道を今回の編集で巻き込まない。
