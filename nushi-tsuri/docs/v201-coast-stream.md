# v201 — 小島の釣り・北の渓流・二本オールのボート

小島で水に向いても釣れない原因は、同じ座標にある村の建物・橋・小物が沿岸のキャストを遮っていたこと。沿岸では沿岸の岸と水だけ、渓流では渓流の岸と橋だけを調べる。村の壁・橋越しのキャスト制限は維持した。

- 村の北口でA、または上へ進むと星見渓流へ。南の山道でA、または下へ進むと村の同じ北口へ戻る。移動前後で持ち物・体力・釣果を保持。
- 渓流の木の橋を渡り、川・木漏れ日の池・葦の沼で釣れる。川ではヤマメ・ニジマス・アユ、池ではフナ・コイ、沼ではナマズ・ウナギなど、岸と投点の深さに応じた既存魚を選ぶ。
- 準備、キャスト開始、距離による深さ変更まで地域の魚種を保持。星湖の秘餌は山の池で消費せず、星降る湖のヌシ専用のまま。
- 村の建物、採集ポイント、大会NPC、主人公宅、港が渓流の同じ座標へ混ざらない。犬は岸と橋を通って同行する。
- 沿岸のカヌー表示を、木製の二本オールのボートへ変更。男女それぞれ四方向・休止と漕ぎの16フレーム。船体の中心を合わせてオールの動きによる位置ずれを抑える。
- 所有・装備の保存IDは `canoe` を保持。既に持っている舟を買い直す必要はない。価格3500円、移動5マス・体力2消費は維持。タライも従来どおり。
- `stream` の場所を保存し、再開時も山の同じ場所へ戻る。不正な場所は山の道へ戻す。船に乗れるのは沿岸のみ。
- v201のキャッシュに新しいモジュール・背景・ボートを追加。村の背景表示ルールを地域に限定する。

### 渓流

SFC時代の上質な釣りRPGとして、既存の「星降る湖」の村と同じ精密で読みやすいレトロドット絵。横長16:9の上から見た地形。北の岩壁から滝と渓流が流れ、中央に徒歩で渡れる木の橋。左上に森の池、右下に葦の沼。南の村へつながる山道、北の峠と北東の岩窟へ続く道を連続して描く。歩ける岸と通路を分かりやすくし、水の深さ、岩、木の幹、草、土に陰影と細かな質感を入れる。人物、UI、文字、ラベルを入れない。

### ボート

既存の男女主人公と服装・頭身を合わせる、SFC風の精密ドットの木製手漕ぎボート。上・右・下・左を別々に描き、各方向に男の子と女の子の休止／漕ぎの差分を用意する。男の子は紺の帽子と青緑・生成りの服、女の子は赤い帽子と赤い服。丸い縁と先細りの船体、木目、内側の座板、縁の明暗、二本のオールの軸と幅のあるブレード、控えめな水しぶき。主人公の頭、腕、手、足が舟の内側に自然に収まる。背景は透明、ラベル・文字・UIは無し。

アトラスの上下余白は均等ではないため、実測した行の境界 `0,330,626,914,1254` と船体の中心を使う。小さな表示でもオールの先を切らず、隣のスプライトを描かない。
