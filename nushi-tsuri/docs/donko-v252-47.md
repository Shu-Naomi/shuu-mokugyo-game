# v252-47: 川底のドンコ

既存の民家川と水郷の湿地・砂底の小川へ、普通魚「ドンコ」を図鑑番号61として追加。新マップ、釣り道具、カードゲーム仕様はこの変更に含まない。

## 狙い方

- 民家川／砂底の小川の岸際〜中層。小エビ＋ハリ小が基本。ミミズ・川虫でも狙える。
- 夕方〜夜は出会いやすく、昼にも釣れる。出現率・価格・サイズ・ファイト係数はゲーム用の調整値。
- 底で止まり、短く前進する泳ぎ。ファイトでは短い突進、底で踏ん張る間、寄せられる休みを使い分ける。
- 既存のゲージ式・ぬし釣り式、釣果記録、図鑑、食材、水槽、預かり、保存再開の経路へ統合する。既存のぬし解放条件やセーブ形式は変えない。
