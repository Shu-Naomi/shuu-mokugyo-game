# 村の景観②：祖父の時代からある釣り宿

出発点は `village-layout-audit-v251.md` と公開済みサムの `village-sam-redesign.md`。宿は従来の場所・ID `farmhouse` のまま、使い込まれた瓦と木部、短い藍の暖簾、古い「宿」の木札、植木、菜園、物干し、踏みならされた庭を一つの景観として整える。魚屋や新マップの景観を今回に含めない。

## 原画と編集する範囲

別ブランチに保全した内蔵image_genの原画 `assets/village-inn-v251-4.png` を未加工で使用する。1407×1118、2818742bytes、SHA256 `f088186877e9d364365d4f185a0af625b6073aaf71150f55cb1bd3ecd66074bc`。全文プロンプトと入口を合わせた二段階の編集記録は `art-prompts-village-inn.json`。元の村画像を上書きせず、参照切り出し[128,48,272,216]に対し、描いた玄関・門を実測して[120,48,272,216]へ置く。

`scene-layers.js` の宿区画の輪郭でクリップし、サムと同じ `assembleSource` の処理で原画を合成してから、精密レイヤー分割・四季・時刻・天候の処理へ渡す。新しい暖簾・石段・物干しは宿に付属する部品として登録。元の村・サム原画・宿の内装は保持する。

公開済みサムを合成した村との画素比較では、**変更36120画素、宿区画外の差0**。変更は原画座標x136〜388/y68〜248の宿と庭の輪郭内に限る。サム・港・湖・道・他の施設を再描画しない。庭の門は玄関前の南北の踏み跡に合わせ、東西の村道と両側の道を空ける。
