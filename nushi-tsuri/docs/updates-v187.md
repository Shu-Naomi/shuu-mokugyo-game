# v187 操作SE

選ぶ、決定する、戻る時に、それぞれ短い電子音を鳴らす。湖での操作、フィールドメニュー、釣具・図鑑・店、水槽・ワンコ、大会とコンテスト、竿ガチャのボタンに対応する。セレクトボックスの変更やキー操作にも対応する。

## 操作

- ボタンの押下、選択欄の変更に応じて3種類の音を使い分ける。A/B、矢印と決定・戻るキー、竿ガチャ演出内のキー操作も対象。
- 音声は音楽と環境音に使う既存のWeb Audio出力から合成する。短い三角波で、外部の音素材や追加のセーブ項目はない。
- 音を切る操作、非表示、ページ移動では音を止める。Web Audioが再開待ちの時は、古い操作音を後から再生しない。
- 移動・巻き上げの長押しは押した瞬間に1回だけ鳴らす。続けて生じる互換クリックやキーリピート、画面の再描画では再生しない。
- ボタンにフォーカスがある時のEnter入力を通常の操作と重ねず、ブラウザが行うボタン操作に任せる。釣りのA操作は従来のキー操作を使う。
