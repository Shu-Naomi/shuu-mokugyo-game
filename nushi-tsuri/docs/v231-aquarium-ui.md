# v231 魚を主役にした飼育水槽

横画面の水槽で、個体の全記録・育て方・お引越しが縦に積み重なり、下までスクロールすると水槽が見えなくなっていた。通常画面を、絵付きの個体選択・水槽・元気と水質のゲージ・常に見えるお世話ボタンにまとめた。

水槽の切り替えは前後ボタンと写真付きの水槽カード。一匹の観察は水槽の魚、個体写真、全体／一匹ボタンで選ぶ。長いネイティブの個体リストを重ねて表示しない。

体長・サイズ・レベルは普段の画面に残す。出生サイズ、成長量、経験値、お世話日数、性別、世代、星は「記録・管理」の中にまとめる。短い横画面では経験値の細かな表示を記録へ寄せる。お引越し先も水槽カードで選び、「託す」は個体番号と体長を示す確認を保つ。

育て方は挿絵アイコン付きの独立した案内。詳細のパネルだけがスクロールし、背景の水槽のサイズや位置は動かさない。パネルを開いた間は背景の操作を止め、キーボードのTab移動をパネル内に保つ。Escapeと戻るでパネルだけを閉じ、開いたボタンへフォーカスを戻す。

魚と水槽の背景には既存の画像を使う。イサキの成魚画像、個体の大きさ、全体の物理縮尺、泳ぎ、育成ルール、購入価格、保存形式はv230のまま。新しい画面でエサと水換えをしても、一日一回のお世話、全個体の記録、移した個体の育成状態を保つ。

## 確認

- DOM回帰で、詳細の遅延表示、閲覧時の費用・時間・個体記録の維持、パネルのEscapeとフォーカス復帰、通常／ぬしの水槽一覧、切り替えの保存、お世話と再読み込み、一匹の移動と託す確認を検証する。
- 独立したAquarium UIのブラウザ検査で、PC1280×720、横画面タッチ844×390、820×366（DPR1.875）の実描画を記録する。メイン画面の縦スクロール、ゲージの隠れ、操作の画面外へのはみ出し、44pxのタッチ領域、水槽の表示面積、個体写真が自分の描画枠をはみ出さないことを確認する。
- 既存の全回帰とブラウザ検査も実施する。最終結果はPRの検証欄に記録する。
