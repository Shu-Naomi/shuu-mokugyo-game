## 今回の修正

- 舟具屋の西側の見えない壁を縮め、店の前の通路と入口へ歩けるようにした。建物や海の当たり判定は残す。
- 八百屋に購入個数を追加。1〜9個は1個刻み、10個からは10個刻みで100個まで選べる。
- サムの釣りエサも10セットからは10セット刻み。表示した個数・合計額で一括購入し、残金不足では消費しない。
- 星みくじに10連を追加。奉納品10個で既存の抽選を10回行う。1回あたりの確率は従来どおり。結果は店内の一覧にも残り、連打による重複購入を防ぐ。
- 村から家の庭へ入る時は従来どおり左側。庭から村へは右側へ歩き、案内が出たらAで戻る。庭の矢印看板も右へ移動して向きを合わせた。

## アスアルのペットショップ

場所は湖の北東にある水車の家。入口前でAを押す。アスアルとクラウドが迎える。

売り場は「魚の生体」「お世話用品」「コンテスト受付」。既存の16種類の一般魚を購入できる。釣りの図鑑・釣果・最大サイズ記録は購入では増えない。ヌシは釣った記録がある場合だけ飼育水槽から1匹を迎えられ、記録されたサイズで飼育を始める。

## 持ち歩き飼育水槽

「持ち物 → 持ち歩き飼育水槽」、または家の展示水槽の「飼育水槽を開く」から利用できる。家の展示水槽とは別の魚を育てる。6槽を用意し、1槽に1匹、計6匹まで飼育できる。最初の魚のエサ10食も付属する。

魚を選ぶと、サイズ、成長量、元気、水質、今日のエサやり、一緒に過ごした日数が見られる。ズームで泳ぐ姿を大きく眺められる。家の展示水槽にもサイズ表示とズームを追加した。

- エサやり：1匹につき一日1回、エサ1食を消費。
- 成長：エサを食べ、水質40%以上で翌日を迎えると0.10cm成長。種類ごとの最大サイズで止まる。
- 日付をまとめて進めた場合、1回のエサを何日分にも増やして計算しない。
- 水質：一日8%ずつ低下。水換えは一日1回、無料で100%へ戻る。
- 元気：お世話で回復し、お世話がない日には低下する。今回の仕様では魚は死亡しない。
- 魚のエサ：10食100円／100食1,000円。アスアルの店で購入。
- 飼育状況と個体ごとの成長はセーブに保存。釣りの記録や家の展示魚と混同しない。

繁殖は今後の拡張用で、今回の実装には含めない。

## ワンコのなつき度と芸

シュウ・リク・Greyをそれぞれ育てられる。白い♡10個から始まり、ゲージ100%ごとに1個が赤い♥へ。10個とも赤くなった後は同じように金色へ変わり、金色10個でMAXになる。

以前の好感度は割合を維持して移行する。例：旧44/100は新880/2000、旧100/100は金色10個。再読み込みで何度も換算しない。

芸は別のゲージ。100%ごとに🥏が1個現れ、10個でMAX。未獲得のマークは表示しない。

| 行動・効果 | 内容 |
| --- | --- |
| ナデナデ | なつき度＋8。一日3回まで上昇し、その後も撫でられる |
| 芸の練習 | 芸＋25、なつき度＋5。一日1回 |
| おやつ | 既存のおやつの効果。一日1回 |
| おもちゃ | 既存のなつき度に加えて芸＋10。一日1回 |
| わんこキャッチ | 成功1回ごとに芸＋3のボーナス |
| 採集 | なつき度に応じて1〜5個拾う |
| なつき度コンテスト | なつき度を100点満点へ換算 |
| 芸コンテスト | マークに応じて一芸の成功率35〜95% |

## コンテスト

アスアルの店で「なつき度コンテスト」「芸コンテスト」「魚の品評会」を受け付ける。各種目に初級・中級・上級があり、各コースに一日1回参加できる。釣り大会中は受付を休止する。

| コース | 参加費 | 優勝 | 2位 | 3位 |
| --- | ---: | ---: | ---: | ---: |
| 初級 | 100円 | 250円 | 125円 | 62円 |
| 中級 | 300円 | 700円 | 350円 | 175円 |
| 上級 | 800円 | 1,600円 | 800円 | 400円 |

芸は「おすわり・お手・待て・ターン・キャッチ」の5つで審査。魚は種類に合わせた成長・体格45点、元気35点、水質20点で審査する。初級から上級へ対戦相手の基準点が上がる。同点は同順位、0点は賞金なし。

結果・参加費・賞金を一緒に保存する。画面を開き直したり再読み込みしても、結果を再抽選したり同じ賞金を重複受領したりしない。
