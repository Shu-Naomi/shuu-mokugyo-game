# 序盤の村生活と最初の釣り（v252-5）

## 案内の範囲

PR #272 の16場面が終わった後、任意の短い案内を表示する。最初は左の祖父の家へ、室内でメニューから「湖の手帳」、三匹それぞれをナデナデ、村の東のサムの釣具屋、気が向いたら試し釣り、という目安を一つずつ示す。移動・世話・訪問・釣りの順番を制限せず、寄り道中も実際に行ったことを記録する。

案内を押すと既存の「水辺の案内」を開く。家・サムの店・試し釣り池の印は、実際の入口判定・池の入口座標を参照する。通常の図鑑からも同じ場所を探せる。湖の手帳の「村の暮らし」から読み返せる。案内図で「案内をしまう」を選ぶと常時表示を止め、同じ場所から戻せる。

家では既存の玄関、ベッド、台所、水槽、三匹の世話をそのまま使う。施設は見るだけでもよく、睡眠・料理・買い物を必須にしない。手帳は既存の「湖の手帳」を開く。新しい手帳イベントや犬個体は作らない。

## 最初の釣り

既存のサムの初回講習へ案内し、投点・ウキ・アワセ・巻く／糸を送るという既存の段階説明を利用する。ゲージ式とぬし釣り式は現在の選択を保つ。講習を受けずに釣りへ行くこともできる。投げた後に釣りを終えれば「試す」の目安を満たし、釣り上げることを強制しない。

初期装備、貸出の練習竿・練り餌、初回講習修了時のミミズ3匹は既存処理だけを使う。案内には配布・能力補正・時間消費・乱数処理を持たせない。PR #270 の餌ゼロ入口判定、ルアー例外、準備から戻る処理は維持する。

## 保存形式と旧セーブ

新規冒険の最初の保存時だけ、独立した追加コンポーネント `villageGuide.version=1` を作る。既存の `mapVersion`、`lakeStory.version=2`、`introVersion=2`、`petLife.version=6` とスロットキーは変更しない。

| 保存項目 | 実際に確認すること |
| --- | --- |
| `enabled` | 任意の常時案内を表示するか |
| `home` | 祖父の家の室内へ入った |
| `notebook` | 室内で既存の手帳を開いた |
| `dogs` | 既存IDごとに実際にナデナデした。重複なし |
| `sam` | サムの店を開いた |
| `fishing` | 実際に投げた釣りを終えた |

この項目がない旧セーブには自動追加しない。旧版でオープニング途中だったセーブや、読み返しからも自動開始しない。旧冒険でも手帳から任意に案内図を見られるが、進行記録を強制しない。未知のコンポーネント版はそのまま保持し、自動案内には利用しない。

進行は既存の `save()` に記録する。保存失敗時は既存の未保存表示を使い、記録をメモリに残して操作を継続する。次の保存成功時に反映する。別スロットや名前・性別・お気に入り・育成・水槽のデータを移し替えない。

## 検証方針

`village-first-steps.test.cjs` で旧／新セーブ、順不同と重複、実際の家の出入り・手帳・三匹、案内の戻り先、案内をしまう操作、保存失敗、両釣り方式、初回報酬、最後の餌と復帰を確認する。既存のオープニング・案内図・餌切れテストも利用する。

ブラウザでは1280×720、タッチ844×390、タッチ820×366/DPR1.875で、新規設定と16場面の終了から実際の移動操作で家・設備・三匹・サム・釣り場へ向かう。道を塞ぐ原因が見つかった場合だけ、入口と既存の壁を保った最小修正を行う。新マップ・魚・施設や釣りシステムの作り直しは含めない。
