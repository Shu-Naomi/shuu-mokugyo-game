# v251 漁船で渡る潮風島

2026-10-29追記: 道・砂浜・桟橋と原画のずれは [通行判定修正 v252-16](offshore-collision-v252-16.md) で補正した。

港の船長タツへ往復800円を支払い、専用の漁船で潮風島へ渡る。片道はゲーム内1時間。帰りの運賃も出発時に含め、船は島の船着き場で待つ。所持金や体力が0でも帰れる。購入チケットや個人のボート装備は不要。既存の沿岸の小島と個人の舟は従来どおり。

支払いは確認した出発時に一度だけ。相談・取消・残高不足・大会中・二重入力では支払いと移動を行わない。島のセーブ再開で再課金しない。保存形式は既存のmapRegionと座標を使い、島はoffshoreとして復元する。古い村・沿岸・山の保存を保持し、別の冒険のセーブへ書き込まない。

専用原画の道・階段・岩場に合わせた歩行判定で、船着き場、休憩所、西の磯、東の潮目、灯台のふもとを接続する。水上や崖の上を歩かせず、島から個人の舟に乗る経路も作らない。休憩所では無料で30分休み、体力を30回復する。

原画は内蔵image_genで魚3枚、島背景、漁船を新規作成し、元PNGを加工せず登録する。プロンプトはart-prompts-v251.json。

一次資料：Honda釣魚図鑑 [シマアジ](https://www.honda.co.jp/fishing/picture-book/shimaaji/)、[イシガキダイ](https://www.honda.co.jp/fishing/picture-book/ishigakidai/)、[アカハタ](https://www.honda.co.jp/fishing/picture-book/akahata/)。魚体の特徴と餌の傾向を参照する。

検証：経路の接続、支払い・取消・不足・二重入力、島での保存再開と無料帰港、両方式での通常抽選と記録・飼育・保存、97段階の原画描画を単体で確認する。PCとタッチ2画面では実際の操作で出航し、島を歩き、専用魚を取り込み、再読み込み後に帰港する。公開後も同じ3画面で確認する。タッチはChromium想定で、実機確認とは区別する。

## 画面検証で見つけた調整

最初の横画面ブラウザ検証では、イシガキダイのゲージ式で糸切れが起きた。テンション65%まで引き、そこから600ms遅れで離す操作が原因で、同じ物理処理を使うDOM検証でも再現した。ゲーム側の魚の力・ゲージ物理は変えず、テストの操作を表示ゲージ45%で離し、20%未満で引き直す判断へ変更。判断からの反応時間は600msを維持する。新魚3種の最大サイズを両方式で釣り切る6件の回帰を追加し、計15件の離島テストが成功した。

横画面の実画像で、運賃案内の見出しのコントラストと到着地点での船長との重なりも確認。見出しを濃い茶にし、船長の足元を既存の歩ける桟橋上でずらした。道・海・料金・セーブの処理は変えない。
