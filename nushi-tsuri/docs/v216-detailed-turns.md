# v216 — 正面の厚みを残した振り向き

v214公開後、スズキとクロダイが斜め・正面・反対側へ急に切り替わるという実機の報告を受けた。七枚の原画を97段階へ拡大変形しても、顔やひれの角度の種類は増えない。スズキ・クロダイは25方向の専用原画へ変更し、v215で準備したホンモロコ・アユの25方向の原画も一緒に導入する。

原画を透過で重ねず、一枚の目・鱗・ひれを保って描く。正面の頭と胸びれの厚み、口元への針の追従を保つ。クロダイの左側面直前の一枚は誤って再び正面を向いていたため、対応する右寄りの原画を左右反転して使う。元のPNGを書き換えない。

全24種について、水槽の端での旋回に少なくとも1.8秒を確保する。速い魚や六匹の水槽でも途中の向きを見る時間を取る。一匹の拡大も1.8秒とする。通常の横方向の尾振りと魚の移動を保ち、ファイト計算は変更しない。

描画の実画素検査では四種の97姿勢で輪郭の欠け・画面端での切れ・正面の厚みを確認し、クロダイが側面直前で再び正面へ戻らないことを検査する。水槽の全24種×六匹を60fpsで観測し、旋回時間と位置の連続性を検査する。実ブラウザのPC・横画面スマホで四種100姿勢、導入の前後移動・途中再開・読み返し、料理の効果・保存、既存のファイトと水槽の操作を確認する。
