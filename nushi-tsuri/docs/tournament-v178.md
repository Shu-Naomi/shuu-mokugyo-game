# 大会の参加費・賞品・記録（第3段階・v178）

星湖フナ大会に参加費と順位賞を追加した。サムの受付で所持金、参加費、全賞品と受取条件を確認できる。参加ボタンを押すとゲーム内のお金3,000円を一度だけ支払い、大会を開始する。足りない場合は不足額を表示し、参加できない。

| 成績 | 賞品 |
| --- | --- |
| 1位 | 1,500円、星ぶどう3個、活き小魚3個、初優勝時に星湖フナ杯 |
| 2位 | 800円、星ぶどう1個、オキアミ3個 |
| 3位 | 300円、オキアミ2個 |
| 参加賞 | ミミズ3個 |

順位賞と優勝記録は9投を終えて対象魚を1匹以上釣った大会で獲得する。同順位なら同じ賞品。圏外、対象魚なし、途中終了、療養による終了は1投以上で参加賞となる。0投で終了すると賞品はなく、参加費は返却しない。相手の途中経過が少ないうちに計量して順位賞を得ることはできない。

通常の釣果、図鑑、魚の売却代金は従来どおり別途残る。希少なぬし専用エサは賞品に含めない。

## 成績とトロフィー

サムの大会受付に「大会の記録・トロフィー」を追加した。出場数、完走数、優勝回数、最高順位、最高合計、前回の成績と初優勝日時を保存する。最高記録は完走した大会のみで更新する。途中終了も前回の成績と出場数に残る。

星湖フナ杯は初優勝で一つ獲得し、記録画面と持ち物に表示する。再優勝では優勝回数が増え、通常の賞金・食料・エサは再び受け取れる。トロフィーの所有は優勝記録から判定し、二つの所有情報が食い違わないようにした。家への飾り付けは後続段階。

## 保存と旧版の継続

大会のNPC保存形式はversion 2のままにし、参加時の賞品規則を独立した`rewardRulesVersion`として保存する。新しい大会は規則1。v174の旧大会形式と、v175〜177で参加済みの大会は規則0として、参加時の無料・賞品なしの条件で終了する。途中のセーブに参加費を後付けせず、その回を新設の恒久記録にも加えない。次の参加から新しい条件になる。

結果画面は受取予定の表示のみ。終了ボタン、右上の終了、B、Escapeのいずれも同じ精算処理へ進む。賞品と成績を更新し、大会結果を終了済みにしてから一つのセーブに書き込む。連打や保存後の再開では二重に付与しない。結果を閉じる前に再開すると未受取の結果へ戻る。

端末の保存容量などで書き込みが失敗した場合は既存の未保存表示を出し、進行をメモリ内に保持する。保存を再試行しても同じ結果を再付与しない。未保存のまま画面を破棄した場合に進行を保持できない点は既存の保存方式と同じ。
