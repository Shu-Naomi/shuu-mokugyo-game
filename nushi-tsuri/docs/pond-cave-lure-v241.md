# v241: 峠の池・地下湖の魚・スプーン

## 峠の池

元の1672×941背景から池岸と土の道を測り直した。旧座標では、北側の森や南東の草地を歩ける一方、実際の道を外れていた。池の輪道、南の入口、北東のつづら折り、沼への出口を接続する。

釣り人の小屋は11×10から20×18のワールド寸法へ戻し、道の東側の扉位置(227,75)へ移す。壁は主道に張り出さず、短い小道から入れる。古い保存位置が小数座標へ復帰した際、壁ぎりぎりで入室判定から漏れる隙間も解消した。

元の「四方向とも完全に動けない」という実セーブの現象自体は未再現。今回の確認では古い右岸位置(219,66)の復帰、右岸・左岸の周回、小屋の出入り、渓流・沼との往復、再開を検証する。実機での最終確認済みとは扱わない。

## 岩窟の地下湖

通常魚をフナ・コイ・ナマズ・ウナギの4種から9種へ拡張する。ドジョウ・カジカ・カマツカ・ウグイと、新魚ギギを加える。距離で決まる岸際・中層・深場によって出現比率を変える。これは渓流とつながる架空の地下湖でのゲーム配置であり、全種が自然界の洞窟に常住するという解説ではない。

ギギは図鑑46番。独立した8方向の原画、口と針の接点、サイズ、通常の餌と針、釣果履歴、料理素材、水槽、育成用カタログ、保存・復帰へ接続する。川虫・ミミズ・小エビで釣れ、星見渓流の深場にも出現する。夕方・夜の重みを高める。ルアーの購入はコンプリート条件にしない。

ギギの学名・生態・尾びれの特徴の確認元：
- [大阪府立環境農林水産総合研究所](https://www.knsk-osaka.jp/zukan/zukan_database/tansui/2150b2c26b1c855/7450b5a172e6aca.html)
- [新潟市水族館マリンピア日本海](https://www.marinepia.or.jp/picturebook/fish/entry-11216.html)

図鑑の文章は独自の短い要約。価格、サイズ帯、釣り場、出現比、強さはゲーム用の調整値。原画は組み込みの画像生成で制作し、`assets/fish-gigi-v241.png`へ保存。元画像の透明度を保ち、既存の魚レンダラーで各ポーズを取り出す。

## スプーン

既存の「誘い → 魚が接近 → 食いつき → アワセ → 選んだファイト」を維持する。Aを長く押すと巻く速さが上がり、離すと減速して沈む。短く巻く・止めると魚が寄り、速く巻き続けると追うのをやめる。手前まで巻けば回収して終了する。Bからの回収も維持する。

これは9月29日更新の改修仕様書第3章にある操作案をもとにした初回調整。速さ・沈下量・接近の数値は最終バランスとして固定しない。常時すべての魚影を並べる機能は追加しない。

食いついた後は新しいA入力が必要で、アワセの押下を最初の巻きへ流用しない。ゲージ式・ぬし釣り式とも同じ個体を引き継ぐ。背景移行中はルアーの動きも止め、復帰時には長押しを解除する。失敗・回収で餌やスプーンを追加消費せず、時間を二重計上せず、釣果を付けない。

v238で増えた6魚種にも専用の竿強度・スプーン相性を登録する。従来の未登録時の一律値では、ヒメマスやマサバのスプーンへの反応も弱くなっていた。
