# v204 — 今のメロディーを残した生楽器音源アレンジ

現在使われている16曲を、実際の楽器のサンプルを使う音源でアレンジする。新しい曲に差し替えず、音程・オクターブ・発音時刻・音符の長さ・テンポ・ループの長さを元の曲と一致させる。四季はv183、部屋と店はv170、大会はv186の作曲データをそのまま参照し、上級ライバル戦のブリッジで省略される音も元の演奏どおりにする。

## アレンジ

| 曲 | 楽器と雰囲気 |
| --- | --- |
| 上級ライバル戦「名手への挑戦・火花の水面」 | 元のブラス旋律、左右の歪んだギター、フィンガーベース、弦、ピチカート、生ドラム。ブリッジで伴奏を抑え、最後の8小節でシンバルと弦を戻す。152 BPM、32小節、主旋律203音を保持。 |
| 湖の釣り大会 | トランペット、ホルン、弦、ミュートギター、ベース、ドラム。 |
| 春・冬 | アコースティックピアノ、ナイロンギター、弦、コントラバス。冬は柔らかなタッチと控えめなグロッケン。 |
| 夏・秋 | 夏はパンフルートとギター、マリンバ、手打ち打楽器。秋はスチールギター、アコーディオン、ブラシドラム。 |
| 家・各店・港・宿・神社 | 琴、三味線、フルート、尺八など元の曲に近い楽器を主役にして、ギターや弦、コントラバスを添える。 |
| ペット・魚の大会 | ピチカートのワルツ、ビブラフォンとハープの伴奏。 |

主旋律だけはタイミングを動かさず、伴奏のストロークと音の強弱で表情をつける。左右のギターは別のストロークとして発音する。音源を3周分演奏して3周目を採り、直前の楽器の余韻とリバーブを冒頭へ残す。末尾2 msの波形を接続し、曲を丸ごとフェードアウトしたり無音を挟んだりしない。MP3は44.1 kHz・ステレオ・160 kbps。ステレオと等電力モノラルの両方にピークの余裕を残す。

ゲームの選曲・通常釣りの水音・ミュート・復帰処理は従来のプレイヤーを使う。メタデータとオフラインキャッシュをv204へ更新し、旧16曲をキャッシュの対象から外す。鳥の環境音は既存の2曲を残す。音源バンクとMIDIはプレイ時にはダウンロードしない。

## 音源と再生成

録音用音源はS. Christian Collinsの[GeneralUser GS](https://github.com/mrbumpy409/GeneralUser-GS)、2.0.3。使用リビジョンは`684543d5e5efaef08d02be50dcda8d552478fa60`。バンクのSHA-256は`9575028c7a1f589f5770fccc8cff2734566af40cd26ed836944e9a5152688cfe`。使用許諾全文を`assets/audio/music-v204/GeneralUser-GS-LICENSE.txt`に保存する。バンクはリポジトリに含めず、録音にだけ使う。生演奏を収録した曲ではなく、楽器サンプルによるアレンジ。

必要なもの: Python 3、numpy、scipy、ffmpeg、libfluidsynth 2.3以上。バンクを上記リビジョンから取得して次を実行する。

```sh
python nushi-tsuri/tools/arrange-soundtrack-v204.py --soundfont /path/to/GeneralUser-GS.sf2
# お気に入りの上級戦だけを作る場合:
python nushi-tsuri/tools/arrange-soundtrack-v204.py --soundfont /path/to/GeneralUser-GS.sf2 --track tournament-masters
```

`NUSHI_FLUIDSYNTH_LIBRARY`で共有ライブラリを明示できる。`--wav-dir /path/to/folder`で試聴用WAVも出力する。MP3の全サンプルをデコードして長さを確認してから既存の録音を置き換える。

旧作曲プログラムを実行し、実際の主旋律の発音呼び出しを捕捉する。その演奏をそのまま新音源のチャンネル0へ渡すため、文字列の音符を別の解釈で読み直さない。全16曲・1006音の参照演奏、元の作曲ファイルと録音のSHA-256、楽器設定を`arrangement.json`に記録し、各曲のMIDIも保存する。

## 検証

- `music-arrangements-v204.test.cjs`: 保存したMIDIを独立に読み、1006音の音程・発音時刻・長さを元の演奏と比較。元の作曲データが変わっていないこと、テンポとループ長、録音のハッシュを確認する。
- `soundscape.test.cjs`と大会の既存試験: 16曲と鳥の音を全てデコード。無音・切れた録音・クリッピング、曲の切り替え、遅い読み込み、音を切る操作、釣り大会と通常釣りを確認する。
- `browser-v202.smoke.cjs`: Chromiumで16曲を実際にデコードし、上級戦を開始して音が鳴ることとミュートからの復帰を、パソコンと横向きスマホで確認。実際のAudioBufferSourceを曲の終わりから再生してループ接続を検査する。v203の道と橋の操作試験も残す。
- mainの公開確認: HTML、サービスワーカー、楽曲メタデータと新しい16曲の公開バイトをコミットと比較し、公開URLでも同じ操作と音声の試験を実行する。
