# 星降る湖・序盤オープニング（v252-2）

PR #267 の「はじめから → 主人公設定 → 犬選択 → 冒険開始」の直後を、既存の導入・会話送り・セーブ機能で拡張する。タイトルや初回設定、ゲームの進行条件は作り直さない。

## 物語と表示

短い16場面で、帰郷と幼少期の釣りの記憶、祖父の手帳、生物研究員だった祖父の願い、サムの誘いと主人公の断り、三匹との再会、当面の村暮らしへつなぐ。主人公はヌシ釣りを約束しない。自由行動の直前と直後に、家・三匹の世話・サムの店という小さな目的を案内する。

- `lake-intro.js` が台本・場面ID・既存画像による描画を持つ。会話ウィンドウと文字送りは既存の `lakeIntro` / `ShuPlayerOptions.typer` を使用。
- 名前・性別・お気に入りは同じスロットの `playerName` / `avatar` / `dog` / `dogNames` を参照。入力の正規化も PR #266 の関数を利用し、表示はエスケープする。
- 主人公、サム、シュウ・リク・Grey、家、村は既存の画像とIDを使用。犬やマップ、施設を追加しない。お気に入り犬を主人公の隣に描く。
- 最後は既存の村の開始地点（家のすぐ右）で自由行動へ戻す。位置や育成、釣り、水槽、黄金フナ、所持品、ゲーム時刻は物語のために書き換えない。
- 前の頁、次の頁、本文タップで全文、スキップ、既存メニュー「湖の手帳」からの読み返しを利用できる。

## セーブ互換性

`lakeStory.version` を **1 → 2** に更新する。スロットキー、全体の `mapVersion`、ワンコ・水槽の `petLife.version=6` は変更しない。

| フィールド | 内容 |
| --- | --- |
| `introSeen` | 完了・スキップ済み。既存の意味を維持 |
| `introPending` | 明示的に進行途中。既存の意味を維持 |
| `introVersion: 2` | 新しい導入の保存形式 |
| `introStep` | 再開する場面の安定したID |
| `introPage` | 現在の数値位置。従来フィールドも残す |

表示するたびに、その場面を既存の `save()` で保存する。再開時は有効な場面IDを優先する。旧版で明示的に途中だった数値位置は、次の意味の近い場面に移す。

| 旧 `introPage` | 再開する `introStep` |
| --- | --- |
| 0 | `arrival` |
| 1 | `notebook` |
| 2 | `sam` |
| 3 | `puppies` |
| 4 | `decision` |

冒険済みの旧セーブに導入情報がなくても、強制再生しない。完了済みなら途中フラグより完了を優先する。読み返しは完了・途中位置・訪問記録を書き換えない。タイトルの既存設定で名前やお気に入りを変更した後は、再開・読み返しとも現在の表示名を使う。

保存が失敗した場合は「未保存」を表示し、読書と自由行動は続けられる。保存先のデータは最後に成功した場面のまま残り、次の保存成功時に現在の状態を記録する。途中で終了しても、最後の保存場面から再開できる。
