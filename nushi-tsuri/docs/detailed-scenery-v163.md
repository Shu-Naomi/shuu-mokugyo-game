# v163 — 精密な景観を保つレイヤー構造

v161の簡略化された景観を品質基準にせず、保存されていた精密な村の画像と、v160主人公宅の外観・内装を復元した。静止部分を描き直すためのタイル化は行わない。

## 修正対象と品質基準

| 対象 | 復元した表現 | 分離単位 |
| --- | --- | --- |
| 村、湖、小川、砂浜、船着場 | 元画像の自然な岸、石、草、地面の陰影 | 地面・道・水・岩・桟橋 |
| 家、店、神社 | 瓦、木目、建物の厚み、生活用品 | 建物ごとのマスクと付属品 |
| 木、草、柵、小物 | 葉の密度、枝、陰影、重なり | 木・草・柵・小物・前景 |
| 主人公宅 | v160の1774×887画素を維持 | 外観、家具、床、壁、水槽ガラス、前景 |
| 水上・水中、施設内部 | 各場所の既存の精密画像 | 水面、岸、背景、家具などの領域 |

背景を動かせる形へ分けることが目的で、アート品質を落とす処理は追加していない。主人公・犬の表示倍率、家の床座標、釣りの魚データは維持する。

## 実装

- `scene-layers.js`: 元画像の座標を使った部品マスク、分類、親子関係、元画像と補完下地の対応。衝突用タイルとは別のデータ。
- `layered-scenery.js`: 各画素の所属を一つに決めて分割し、元の解像度で合成。地面に建物や家具を二重に焼き込まない。部品を隠す・移動する・画像を差し替える操作を描画APIで扱える。
- 静止画、木・草の揺れと水のきらめき、前景を別キャンバスへ描画。木の根元を固定し、葉先の移動は元画像の約1画素以内。きらめきは水のマスクの内部だけに描く。
- `scenery-worker.js`: 対応ブラウザでは画像分割・色調処理を別スレッドで実行。未対応時も同じ画素処理を使用する。原画を表示したまま準備でき、簡略画像への置き換えは行わない。
- 元の朝・昼・夕・夜の釣り場画像を再利用。既存時計から明け方と四季の色調を決め、陰影と質感を残す。季節の変化は植物・水・室内の光を中心とした色調変化で、季節ごとの建て替えや新しいゲームルールではない。
- 非同期読み込みには世代番号を付ける。家の出入りや水深・時間帯変更後に古い読み込みが完了しても、新しい場面を上書きしない。分割済み景観3件、画像6件を上限としてキャッシュする。
- 景観のアニメーションは共通の最大12fps。隠れた画面は描かず、非表示・ページ離脱で停止し、動きを減らす設定に従う。

## 既存システムへの影響

画面への接続は `index.html` と `pixel-scenes.css`、オフライン更新は `sw.js` で行う。水槽の生きた魚は従来どおり別の表示で、精密内装のガラス位置へ合わせ直した。

建物・水・橋・家の通路と家具の判定を維持。簡略版の木に合わせていた障害物を、復元した原画に見える幹6か所へ合わせた。既に歩けていた港の接続2か所には、元画像の桟橋の板を再利用して足場を表示する。

釣り、料理、犬、図鑑、掲示板、セーブ形式や保存内容の変更はない。未マージだったv162のキャストの時計・ウキと糸の連続性、犬の足元の修正も含めた。旧 `ShuPixel.draw*` 景観描画はゲーム画面から呼ばない。

2026-09-09、全43テスト通過。

```sh

```

- 村・主人公宅の外観・内装を元解像度で分割／再合成し、元画像との画素差0を確認。春・昼の静止時を比較し、既存通路を可視化する港の足場2か所は比較対象から分けた。静止・動き・前景の3キャンバスの合成も同じ結果。
- 全24景観×四季×5時間帯＝480通りの実画像描画。春・昼は各元画像と一致し、季節・時間で質感を維持して変化する。
- 建物・机・水槽を隠す／動かすと補完下地が現れること、付属品の親子関係、岸へ光が漏れないこと、木の足元が動かないことを確認。
- 遅れた読み込み、画面非表示／復帰、キャッシュ上限、オフライン資源の一致を確認。
- 村の各施設への到達、家の通路・家具・水槽のA操作、魚の入れ替え・泳ぎ・家の出入り・セーブ／ロード、3匹の犬、料理・図鑑・掲示板、キャスト・餌消費・釣りの同期を回帰確認。

`detailed-scenery-v163-preview.png` は実際の景観描画コードとゲーム内スプライトから作成した確認画像。ブラウザのスクリーンショットではない。

検証範囲で既知の不具合は残っていない。ブラウザプレビューがブロックされているため、スマホ実機の操作感・実測fps・Worker経路の実ブラウザ動作は未確認。マップと家の補完下地を用意済みで、ほかの施設の大きな家具移動などで新たに見える裏側は、その変更時に補完画像を足す構造としている。
