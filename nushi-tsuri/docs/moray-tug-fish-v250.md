# v250 ウツボの泳ぎ・魚の逃走と引きどころ・海の2魚種

2026年10月21日の直美の依頼：ウツボの動きの違和感を直す。ぬし釣り式で魚の番の引き出しを強め、魚の動きと糸を読む駆け引きへ。魚種も追加する。

## ぬし釣り式

- 基準は保存文書「星降る湖_改修仕様書_2026-09-28.md」v0.6の第1章。右へ走る間は離す、糸が緩んだらAで左の水面へ寄せる、顔を振る予兆で離すという工程を維持した。アワセは従来どおり別の新しい押下が必要。
- 逃走の実距離係数を1tick（120ms）あたり0.018から0.06へ。正しく離した後の倍率も0.75から0.85へ。既存の魚種別の走る速さ・緩急を、距離と泳ぎに共用する。投点を越えても、画面右端でも実距離と追走背景が進む。
- 魚は実際に走ったtickだけ徐々に疲れる。100tick＝12秒の累積した逃走で疲労の上限。上限でも泳ぐ速さは初期の75%、引く力は55%残る。休止、背面、糸の緩みを無視している時間では疲労を増やさない。疲れた魚も逃走中は毎tick糸を引き出す。
- 張力と糸切れ、1440msの顔振り予兆、720msの反応猶予、1080msの危険な引きっぱなしの限界、初期竿ではぬしを取り切れない制限を維持。ゲージ式の距離・張力計算は変更しない。
- 係数・疲労・魚種別の時間は本作の調整値。参考作品の内部数値を解析・再現したという意味ではない。手がかりを読み、離して距離を譲り、引きどころで取り返す体験を基準に検証する。

## ウツボ

- 従来はウナギ由来の素早い蛇行・回転と、口の開閉による胴体全体の曲がりの切り替えがあった。専用の岩穴への走りと、体をほどく引きどころへ変更し、全身の急な切り返しを抑えた。
- 内蔵画像生成で、巻き上がった尾を浅いS字の泳ぐ姿へ修正した透明8姿勢の新原画。PNG自体は加工せず登録する。開口原画は左向きだったため、描画時のmouthFlipと均一な倍率補正で右向きの閉口姿へ揃える。
- 長い胴体は横へ伸び縮みさせず、一枚の魚体の列を一回ずつ移動して、頭を安定させたまま胴体から尾へ波を送る。正面への旋回中は波を弱める。口・ハリの基準点を維持し、画面の端で体を切らない。
- 戦闘と水槽の双方に泳ぐ位相を渡す。元のウツボの種ID・図鑑番号54・釣果・保存・飼育は維持。

## 新しく迎えるブリもモジャコから

v249にはモジャコの原画と10cm未満の段階判定があり、繁殖で生まれる子は1.5cmだった。ショップだけ24cmのためワカシから始まっていた。v250では購入時の体長を独立した`purchaseSize`で1.5cmにする。店頭にも「モジャコから育てる」と表示する。野生のサイズ階級・釣果のブリという魚種・カタログの基準体長は変えない。

復元時はショップ出身のブリにも1.5cmを許容し、再読み込みで野生の最小体長へ引き上げられることを防ぐ。既存の24cm以上の個体の体長・出生体長・ID・性別・世代・成長記録は保つ。既存の卵と成魚の繁殖経過も保持し、80cm・異性・水質・給餌・3日の成立条件、孵化日、次世代の1.5cmは変更しない。他魚種の購入サイズと不正な稚魚サイズの修復も維持する。

既存個体と卵の保存復元、新規購入直後の保存復元、モジャコからの実際の給餌成長を単体で確認する。水槽のブラウザ検証にもPCとタッチ2画面で新規モジャコの購入・原画表示・再読み込みを追加する。
