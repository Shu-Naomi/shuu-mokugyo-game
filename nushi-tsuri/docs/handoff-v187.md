## 実装

- ui-feedback.js は `ShuUiFeedback.create` と `createPlayer` を公開。入力イベントにだけ応答し、UIの再描画では鳴らさない。
- 出力は既存のゲーム音声の context/master に接続。ミュート、ページ非表示、ページ終了で停止する。閉じた・停止中の context では再生しない。
- index.html のフィールドキー操作と fortune-capsules.js のガチャ内キー操作に接続。押し続ける移動操作と互換クリックは1回の音にまとめる。
- SWキャッシュをv187に更新。新スクリプトをオフライン登録。保存データの変更はない。
- 関連43テスト成功。画面のボタン・長押し・ミュート・非表示の実際のイベントと、ガチャ・コンテスト・音楽・オフラインキャッシュの既存動作を検証。Android実機での音量と音色は未確認。
