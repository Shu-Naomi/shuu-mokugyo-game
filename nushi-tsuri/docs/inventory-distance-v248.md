# v248 持ち物・タックルと逃走距離

直美の依頼：主人公メニューの持ち物とタックルの重複を整理し、古いUIを見やすくする。ぬし釣り式では右へ逃げる魚との距離を実際に増やす。魚種も追加する。

## 道具を探して使う

- フィールドの入口を「持ち物・装備」に一本化。持ち物／タックル／身支度の3タブ。釣り場のBで開く投げる前の仕掛け変更は継続。
- 持ち物は食べ物、食材、犬のおやつ、犬のおもちゃ、竿のパーツ、収集品、奉納品。餌・ルアー・ハリの確認だけの重複した棚をなくし、タックルの選択と所持数表示にまとめる。料理と餌・おやつで共用する材料の確認は残す。
- お店と揃えた明るい紙と木の全幅一覧。名前・所持数・選択中を行に表示。説明と元の「食べる／セットする／装備する」ボタン、詳細、ページ送りを下の一列に置く。
- 元の所持品・装備・売却・重ね強化の処理を移動して使い、一覧や詳細の閲覧では所持品や保存値を変えない。詳細を閉じると元の操作へフォーカスを戻す。
- 使用・装備の結果は下の説明欄に表示して操作ボタンを覆わない。別の品や分類を選ぶと通常の説明へ戻る。

## 魚が右へ逃げる距離

以前は、正しくAを離した後の逃走では距離を減らさず、さらに進捗の下限0が投点より先の距離を切り捨てていた。背景と泳ぐ姿だけが進んでいた。

ぬし釣り式は各120msの実戦闘tickで、魚種の走り方と強弱から実際に糸を送り出す。同じ走る速さを泳ぐ姿にも使用する。右端で魚を画面内に収めた後も距離と追走背景は進む。適切に糸を緩めると取られる距離を抑えられるが、距離自体は止まらない。無理に引くとより糸を取られ、従来どおり糸が切れる。

進捗は0より小さい値も保持し、水面までの距離は投点より大きい値を表示できる。距離バーの描画幅は100%まで。画面上の泳げる範囲と取り込み位置の補間は0〜1に制限し、魚が画面外へ押し出されるのを防ぐ。背景は実際の距離差から進める。停止中に壁時計の経過をまとめて加算しない。

引ける時間の魚種別の乱数、初回の正しい入力で確保される引ける時間、1.44秒の首振り、0.72秒の反応猶予、糸切れの追走、左の水面への取り込みを継続。ゲージ式の距離計算は変更しない。
