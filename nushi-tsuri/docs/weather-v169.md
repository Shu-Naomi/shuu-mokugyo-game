# v169 — 日替わり天気

晴れ・曇り・小雨を追加。HUD、釣り支度、サムの店、屋外の景色と雨音が同じ天気を参照する。

ゲーム内の日付から天気を決めるため、既存セーブに追加の保存項目は不要。同じ日の再開では天気が変わらない。午前0時に更新され、ベッドで翌朝まで寝ると翌日の天気になる。初日から3日間は晴れ→曇り→小雨、その後は日付のハッシュで約52%・30%・18%。ゲーム内の抽選用乱数は消費しない。

| 天気 | 出現ウェイトの小さなボーナス |
|---|---|
| 晴れ | モロコ ×1.08、アユ ×1.10 |
| 曇り | ブラックバス・ヤマメ・ニジマス ×1.12、スズキ ×1.08 |
| 小雨 | ナマズ・ウナギ ×1.18、ブラックバス・スズキ ×1.10、ヤマメ ×1.08 |

釣り場、餌、時刻、距離の既存ウェイトに掛け、既存の合計値で抽選する。新しい魚を釣り場に追加しない。試し釣りのフナと、湖の深場での星湖の秘餌のヌシ確定は維持。

既存の精細な背景を淡く曇らせ、屋外だけに細い雨と水面の波紋を描く。波紋の全周が水のマスク内に入る位置を事前計算。屋内や水中の色と動きは変えず、動きを減らす設定では雨のアニメーションも停止する。天気をキャッシュキーに含め、日付変更後の旧景色の残留を防ぐ。背景と効果は従来どおり共通の12fpsループ、対応端末では別Workerで準備する。

雨音は3秒のステレオノイズとフィルターで合成し、外部音源は使用しない。既存の音量スイッチ・音声解除操作に従い、1本のループだけを再生する。店内・家の中・水中・消音・画面非表示で止まり、戻ると再開。音量を短くフェードして境目をなじませる。

## 確認

天気、精細背景、キャスティング、釣りUI同期、オフラインキャッシュの33テストが成功。天気の6テストでは720日分の安定性、セーブ再開、睡眠、サムの表示、実際の魚抽選、試し釣り、合成音の停止・復帰、水面マスク、屋内・水中の保護と天気キャッシュを確認した。

`weather-v169-preview.cjs` はゲーム本体の描画器で比較画像を生成する。`weather-v169-preview.png` は左から晴れ・曇り・小雨。キャスト絵は確認済みのv168を使用。
