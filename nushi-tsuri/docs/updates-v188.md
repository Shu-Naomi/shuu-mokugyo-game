# v188 飼育魚の繁殖・世代・売買

アスアルのペットショップと持ち歩き水槽を更新。水槽の魚は購入時に雌雄が決まり、魚を選ぶと世代・★・雌雄を確認できる。

## 繁殖と育成

- 同種の成魚のオスとメスを同じ水槽に入れ、前日に二匹ともエサを食べた状態で、元気70%以上・翌朝の水質60%以上を3日連続で保つ。水槽に空きがある時、翌朝に稚魚が1匹生まれる。初期体長は成魚の8割以上で、その種の最小体長を下回らない。生まれた魚は親の世代の大きい方から1世代進む。
- 水槽が満員、片方が不在、同じ性別、世話が途切れた、水が汚れている時には出生しない。引っ越し・購入・手放しでその水槽の連続日数はリセット。ヌシは繁殖・買い取りの対象外。出生しても釣果と魚図鑑は増えない。
- ★1から★5まで。一日一回の給餌で体長が成長した日だけ育成日数が進む。初代は6日につき★1、第2世代は5日、第3世代は4日、第4世代以降は3日につき★1増える。★2からは品評会の体格点に★ごとに2点を加える（体格点45点が上限）。
- 自宅のベッド・釣り宿で翌朝を迎えた時は誕生を知らせる。水槽にも当日の誕生を表示。魚の大きさと水槽の方向別ドット絵を稚魚にも使う。

## 購入と買い取り

- 新規ゲームの持ち歩き水槽は1槽、エサは10食。追加水槽はアスアルのお店で2槽目から順に400円、900円、1,500円、2,400円、3,600円で購入。各槽5匹まで、淡水・海水を混ぜられない。購入後の水槽数はセーブされる。
- 既存のセーブは所持していた6槽と魚の位置・体長・成長・お世話・賞金を維持。旧魚の雌雄は保存IDに応じて割り当てる。既存の「アスアルに託す」は従来どおり返金なしで、買い取りと別の操作。
- アスアルの生体販売には、自分でその魚種を一度釣って魚図鑑に登録する必要がある。未登録の魚種は商品一覧に並ばず、購入処理でも拒否する。繁殖・買い取りは釣果に数えない。
- 成魚の体長まで育ち、エサ・水のお世話を3日以上受け、元気60%以上の魚を買い取ってもらえる。価格は元の価格・体長・★・世代で決まる。確認操作の後に魚を水槽から取り除き、所持金を一度だけ増やして保存する。ヌシは対象外。

## 検証

旧セーブの移行と新規ゲーム開始、購入失敗時の所持金、水槽の満員・水の種類、未登録魚種の拒否、連続・中断・別槽・同性・水質・満員での繁殖、星と品評会、成魚の買い取り二重実行と再読み込みをテスト。実際のゲームUIで3回就寝させて誕生通知とセーブまで確認。
