## 描画

aquarium-life.js の orientation() は論理的な向きと描画の反転倍率を分ける。facing を scaleX に渡してはいけない。旋回は5方向の既存画像を使い、flip は常に1。泳ぎの左右反転だけ ±1。index.html の drawAquariumSprite() を自宅と pet-life-ui.js で共用する。メバルは standaloneFishFrameAsset() により個別PNGへ解決する。

関連37テスト成功。全17魚種85方向フレームの実画像と全魚種の描画比較を確認した。新しい画像や音源は追加していない。Android実機は未確認。公開の実施結果はPRに追記する。
