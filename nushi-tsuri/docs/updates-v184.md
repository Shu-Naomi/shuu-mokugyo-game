# v184 水槽の方向別アニメーション

大型アップデートの第1弾。横向きの魚を横幅ゼロまで縮めて裏返していたため、旋回中に紙のように見えていた問題を修正した。

- 全17魚種で、既存の釣り画面用の方向別ドット絵を水槽にも使う。横・斜め・正面・反対側の斜め・横の5方向を順に表示する。画像の新規描き下ろしではなく、水槽で使う方向を増やした変更。
- 持ち歩き飼育水槽、自宅の展示水槽、その拡大表示に適用。
- エサへ向かうとき・食事を終えて戻るときも、現在の向きからなめらかに旋回する。
- 旋回用の画像を事前に読み込み、通常の泳ぎとの切り替えで同じフレーム番号でも正しく描き直す。メバルの個別PNGも対応。
- 魚の幅・高さは方向のために潰さない。通常の泳ぎの左右反転だけは等倍で行う。

魚の所持・体長・給餌・水質・コンテスト記録・図鑑・所持金・水槽数の保存形式は変更していない。

## 確認

関連37テストを確認。aquarium、aquarium-v183、aquarium-v184、pet-life-integration、service-worker。

- 両端の旋回で全5方向を通り、横倍率がゼロや小数にならないこと。
- 実際の全85方向フレームを画像としてデコードし、正面にも見える幅があり、縦横比が一致すること。
- 全17魚種の自宅・拡大・持ち歩きの描画、メバルの個別PNG、同じ番号の泳ぎ／旋回フレームの切り替え。
- 小さい水槽でのはみ出し防止、給餌中の向き、お世話・成長・引っ越し・旧セーブ・再読み込み、非表示時の停止、キャッシュ。
