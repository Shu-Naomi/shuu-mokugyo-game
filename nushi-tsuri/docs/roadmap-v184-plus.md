# 2026-09-20 大型アップデート依頼

直美から実装の依頼。段階に区切って公開してよい。以下は依頼全体の記録で、未実装の項目を実装済みとして扱わない。

## 第1弾 v184：水槽の旋回

- 持ち歩き飼育水槽・自宅の展示水槽・拡大表示で、横向きの魚を横幅ゼロに縮めて反転する描画を廃止する。
- 全17魚種の既存の方向別ドット絵を水槽にも使う。横・斜め・正面・反対側の斜め・横の5方向で顔と胴体の厚みを見せる。
- エサへ向かうときと泳ぎに戻るときも方向別の絵を使う。
- 今いる魚、成長、お世話、所持金、水槽数、図鑑を引き継ぐ。

## 第2弾 v185：カプセルガチャ

- 竿ガチャの単発・10連に、色付きカプセルの排出・開封演出を実装。個別開封とまとめて開封、受け取った結果の保存・再表示に対応。

| 景品 | カプセル |
| --- | --- |
| 星見竿 | 輝くオレンジ |
| ワンコのおもちゃ全般 | 青 |
| ノーマルの釣りエサ | 白 |
| お祝い金 | 金 |
| ぬしエサ | 紫 |

犬のおやつは青、ルアー・竿パーツ・図鑑収集品は白。星見竿やおもちゃの重複時も、抽選で出た景品の色を保ち、代わりに受け取ったものを説明する。

## 第3弾 v186：音・順位演出・ライバル（実装済み）

- 釣り大会には対戦が盛り上がる熱い専用BGM。
- ペットコンテストと魚の品評会には、ファンシーな専用曲。
- 大会・ペットコンテスト・品評会に、それぞれ順位に応じたドット絵アニメーション。
- アスアルたち上級ライバルが湖に集まるのは大会中のみ。店主としてのアスアルのお店は利用できるようにする。
4曲と種目・順位別の舞台を追加。名手は大会終了後に湖から退出する。詳細と検証は updates-v186.md、引き継ぎは handoff-v186.md。

## 第4弾 v187：UIの音（実装済み）

- 選択・決定・戻るの短い操作SEを追加。画面のボタン、プルダウンの選択、キー操作、竿ガチャの演出操作に対応。ミュートと画面非表示で停止し、長押し・互換クリック・再描画では鳴らし直さない。詳細は updates-v187.md。

## 第5弾 v188：繁殖・育成・売買・解放（実装済み）

- 同じ水槽に同魚種の雄と雌を入れ、健康な状態で数日お世話すると稚魚が生まれる。
- 世代を重ねるほど星（ランク）が上がりやすくなる育成要素。
- 育った個体をアスアルに買い取ってもらえる。
- 新しいゲームでは6槽を最初から所持せず、アスアルから水槽を買って解放する。
- 生体販売の魚種は、自分で釣り、図鑑に登録して初めて解放する。

性別・親子・世代・星・繁殖日数・価格等の詳細は実装時にゲーム内で説明する。既存の魚や購入済みの進行を消さずに移行する。すでに所持している水槽を突然利用不能にしない。満員時の出生、日付またぎ、移動、再読み込み、売却の二重報酬、ヌシの一度限りの扱いを確認する。

具体的な条件と検証は updates-v188.md。既存セーブの6槽・既存魚は保護し、完全な新規ゲームだけ1槽から始める。

## 第6弾 v189：飼育魚の成長速度（実装済み）

実際のプレイで毎日0.10cmでは育成に時間がかかりすぎると判明。魚種の最大体長に応じて給餌した翌日の成長を1〜5cmに調整し、水槽の表示と説明を更新。詳細は updates-v189.md。

## 第7弾 v190：水槽の魚を一匹ずつ観察（実装済み）

水槽全体の体長比は維持しながら、泳ぐ魚のタッチ・魚一覧・選択欄から一匹を大きく観察できるようにした。水槽の状態と操作案内も整理。詳細は updates-v190.md。

## 第8弾 v191：エサ・ハリの狙い分けと釣具のドット絵（実装済み）

既存の11種のエサの魚種別相性を整理し、標準装備のハリ小・中・大を追加。魚種の基本サイズ帯に応じて釣れる候補の重みを調整し、個体サイズの抽選には触れない。18種類のエサ・ハリ・小物アイコンを統一したドット絵に変更。ぬし餌は現行の入手方法を維持してハリ大専用にした。詳細は updates-v191.md。

## 第9弾 v192：釣具一覧の説明を読みやすく（実装済み）

公開画面で見つかった金色の釣具ボタン上の説明・所持数の低コントラストを修正し、特に小さな横画面で縮みすぎないようにした。詳細は updates-v192.md。

## 第10弾 v193：スマホ横画面の全画面表示（実装済み）

ホーム画面から起動するアプリ版を全画面表示に設定。右端のAndroid操作バーが占めていた画面幅をゲームに使えるようにした。ブラウザの通常タブとセーブ内容はそのまま。詳細は updates-v193.md。
