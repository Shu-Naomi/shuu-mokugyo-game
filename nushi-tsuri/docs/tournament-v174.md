# 釣り大会 第1段階（v174）

サムの店の「サムの釣り大会」から星湖フナ大会に参加する。
対象は湖で釣ったフナ。朝に固定された釣り場で、ゲーム内90分・最大9投。
1投10分とエサの消費、釣り方、魚の出現・サイズ抽選は既存の処理を使う。

## 基本ルール

- 大会中に釣った対象魚を最大5匹、専用ビクに記録する。5匹未満でも計量する。
- 6匹目以降は、どの魚と入れ替えるか、または新しい魚を逃がすかを選ぶ。
- 合計サイズの大きい方が上位。同点なら最大魚、両方同じなら同順位。
- 第1段階の比較相手は明記したサムの固定参考記録。24.50 / 22.00 / 19.50 / 17.50 / 16.00 cm、合計99.50 cm。
- 他魚種とヌシはビクの対象外。大会中も通常の釣果・図鑑・最大サイズ・金冠・釣具履歴・料理素材・依頼・代金に反映する。
- ビクの入れ替え・リリースは大会の計量対象の選択。通常の釣果や代金を巻き戻さない。
- 空振り、糸切れ、投げた後の回収も1投。投げる前のキャンセル、移動、仕掛け変更は消費なし。
- 大会ビクから途中終了して計量できる。エサ切れでも終了可能。

## 時計と保存

`s.gameMinutes` は既存どおり1投10分進む。大会中の表示・景色・天気・魚の時間帯判定・魚図鑑の釣った時間帯は、開始日の大会設定時刻で固定する。
通常の料理効果や救援待ち時間などは実際に使った時間で判定するため、時計を巻き戻さない。
結果を閉じると大会の表示時刻を解除し、参加前の時刻＋消費した時間へ自然に戻る。
通常BGMとキャスト画面の環境音は従来どおり。大会専用音楽は未追加。

既存セーブの `tournament` フィールドへ、イベントID・開始時刻・投数・ビク・入れ替え待ち・結果状態を保存する。
投げた時点でエサ・時間・投数・進行中マーカーをまとめて保存。
投げた途中の再読み込みは回収済みの一投として再開し、魚やエサを再付与しない。
9投目の入れ替えが残っていれば選択を再開し、決定後に結果を表示する。
結果画面自体も再開できる。古いセーブに大会情報がなくても通常どおり読み込む。
大会中の宿泊・自宅睡眠・無料練習は停止。釣果による緊急搬送時は大会を中断して療養する。

## 追加の境界

`tournament.js` に対象魚・釣り場・時刻・制限時間・ビク容量と採点を分離。
釣り場固有の座標や魚の生成処理を大会へコピーしていない。
順位計算は任意の参加記録を比較でき、第2段階でNPCの釣果を接続できる。

村人NPCの配置・釣果生成、参加費・賞品・優勝記録、専用BGM、特殊演出、別大会、新マップのチケットはこの段階には含めない。
次は基本大会のプレイ確認後に、第2段階のNPCと会場を追加する。

## 検証

`tests/tournament.test.cjs` は容量・9投上限・対象外魚・同点比較・夜/別水域の設定、実際のキャストと通常釣果の連携、最後の魚の選択/結果の再読み込み、途中の投球復帰、エサ切れからの終了を検証する。
既存の移動・天気・音・釣りUI・ガチャ・オフライン更新の回帰テストも実行する。
