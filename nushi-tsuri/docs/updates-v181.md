# 星降る湖 v181 — 名手の相棒犬に鳴き声と動きを追加

サム、リアオ、アスアル、ダンの相棒犬に話しかけると、短い鳴き声とリアクションで返事をする。「もう少し話す」やキーボードのZで、挨拶・甘える仕草・もう一つの反応が順番に見られる。

| 相棒犬 | 鳴き声の雰囲気 | 主な動き |
| --- | --- | --- |
| クロー／リアオ | 少し高めのきびきびした返事 | 立ち上がる、鼻を寄せる、首をかしげる |
| クラウド／アスアル | 軽い明るい返事 | 小さく弾む、頬を寄せる、前かがみで遊びに誘う |
| ジェイミー／ダン | やわらかい返事と甘える声 | 立ち上がって迎える、体を寄せる、首をかしげる |
| チャッピー／サム | 低めで落ち着いた返事 | ゆったり立つ、鼻を寄せて甘える、頭を下げておすわり |

既存の立ち姿・おすわりの絵を使い、しっぽを根元から揺らし、体や顔を小さく動かす。甘える時は安全な足場の範囲で主人公へ少し寄り、ハートが浮かぶ。約2.6秒で元の場所と姿勢へ戻る。犬や主人公の実際の座標、同行犬、好感度、時間、エサ、大会の釣果は変わらない。

## メッセージの重なり

- 画面下の会話中は、方向キーとA・Bの表示を隠す。会話欄の「もう少し話す」「会話を終える」で操作でき、キーボードのZ・X・Escapeも使える。会話を終えると元の操作ボタンが戻る。
- 顔画像の四角い欄とセリフの長方形は維持。セリフ欄の背景を不透明にし、会話ボタンを押しやすい高さにする。
- 水辺などの案内、大会の残り時間・ビク、お知らせを、ステータスの右側の同じ列へ順番に並べる。長い大会開始通知は折り返し、他の表示に重ねない。
- 待機メニューが開いても、大会ビクはステータスとメニューの間から開ける。待機メニューの5秒とステータス表示のタイミングは継続。

## 音と動きの扱い

「ワン」は既存の `assets/audio/dog-pet-bark.mp3` を再利用し、再生速度で4匹の声に違いを付ける。「クゥーン」は短い合成SE `assets/audio/dog-friendly-whine-v181.wav`。制作手順は `tools/compose-dog-whine-v181.py` に保存してあり、外部素材の追加ダウンロードは不要。

音のオン・オフ設定に従い、連打でも鳴き声を重ねない。会話終了、画面を離れた時、音を切った時には停止する。絵の読み込みや再描画だけでは鳴き直さない。端末で動きを減らす設定を使っている場合は、文章と鳴き声で返事をする。

サムの店から「チャッピーに挨拶」を選んだ場合も、店先のチャッピーが反応する。会話終了後はサムの店へ戻る。
