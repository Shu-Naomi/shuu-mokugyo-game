# v203 — 渓流の道と橋の当たり判定

渓流の入口で見えている土の道を進めず、左の木の根元を歩けてしまう問題を修正する。完成背景を240×135の世界座標へ重ねて測り直し、入口、橋の両岸、北の峠、洞窟への曲がり道、池と沼の道を絵に合わせる。新しく入る位置は道の中央の `(152,128)`。木は根元の小さな範囲を通行不可にし、隣の道へ張り出す葉で道を塞がない。

山の移動は4単位先の終点を一度に採用せず、0.25単位ずつ安全性を調べ、通れた1単位の移動を残す。橋の端へ近づく一歩が全て取り消されず、そこで左右へ向き直って渡れる。川や池の水上は歩けず、橋の上では釣りを始められない。村と舟の移動・消費処理は従来どおり。

古い保存位置が新しい判定で木の中になる場合、既存の位置復旧で近い陸地へ戻す。セーブを消したり、持ち物・体力・釣果を初期化したりしない。サービスワーカーと山のモジュールの版を更新し、既存の端末にも修正版を配信する。
