# v214: 水槽の矢印・背景と、魚の原画を保つ描画

選択した魚のタッチボタンに、共通の「選択中」ボタンの黄色い背景が適用されていた。水槽内のボタンには選択中でも透明を指定し、魚より上へ12px幅の下向き矢印を置く。44px以上のタッチ範囲、魚の拡大、一覧・選択欄からの操作を保つ。

水槽は、細かな底砂・小石・苔むした岩・流木・葉脈のある水草・ガラスの継ぎ目を描いた専用の原画に変更。魚が泳ぐ中央の空間を空ける。全体表示と一匹の拡大に同じ原画を使い、水質による濁りやガラス・泡を重ねる。右の説明欄に合わせて水槽自体が縦へ伸びないようにして、底が見える高さにする。画像の制作方法、原プロンプトと本番パスは[v214-art-manifest.json](v214-art-manifest.json)に記録する。

v213の旋回補間は異なる原画の目・鱗・ひれを重ね、列ごとの輪郭に模様を合わせていたため、中間姿勢に二重の目や裂けた鱗を描いていた。横泳ぎも重なった細い画像帯が模様をぼかしていた。v214は最も近い一枚の原画を使い、448×224の各出力画素を一回だけ描く。縦方向の尺度と背骨をそろえ、口元を支点に後ろの身体を曲げる。正面と横向きの口元の差で偽の長い嘴ができる変形も除く。小数の97段階の姿勢、物理更新から独立した描画、尾の横振り、同じ口元への針の追従を継続する。半開きの口で全身を二枚重ねない。

原画ごとに旋回キャッシュを区別し、別画像のフレームを混ぜない。隣の原画や未読込の画像を切り抜かない。24魚種の原画、魚の強さ、海ヌシの取り込み計算、報酬・成長・繁殖・セーブ仕様は維持する。

検証には、異なる色の原画を使って中間旋回・口・尾に混色や半透明の帯が出ない回帰検査を追加。従来の全種の輪郭・種の見分け・針・海ヌシ検査を継続する。PCと横画面スマホの実ブラウザでは、選択中の背景が透明なこと、矢印が魚の外側にあること、タッチと拡大、実背景の読込、全体拡大での底の収まり、原画の色を保つ描画、釣果・魚・所持品の再読込を確認する。拡大した水槽は画面から固定値を引いた高さではなく、見出しの下の残り高さへ収める。画像の遅延読込の検査はdrawImageだけでなく、画素の直接描画にも対応して描画成功を記録する。
