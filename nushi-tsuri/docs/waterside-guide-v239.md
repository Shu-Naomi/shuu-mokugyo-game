# v239 水辺の案内

メニュー → 図鑑 → 「水辺の案内」で、今いる地域の案内図を開く。村、海の小島、星見渓流、峠の池、峠の沼、水郷の湿地、岩窟の地下湖に対応。

右の場所名に触れると、地図の金の枠と短いメモが切り替わる。赤い丸は現在地（自宅内では村につながる家の入口）。水辺、追加した4軒の民家・2か所の売店、山道の出入口を表示する。建物の扉や出口へはプレイヤー自身で歩き、Aで入る・移動する。

新顔6種の釣りメモは、既存の魚定義・水辺別の配合表・エサ名・ハリ名を参照する。価格、抽選率、装備、釣果、セーブ形式を変更しない。通常の図鑑の未発見表示もそのまま。

3件ずつの場所一覧、44px以上の操作ボタン、古紙と木の丸い枠を使用。地形・建物の既存画像は再利用し、原画は変更しない。スマートフォン横画面で案内全体をスクロールせずに読める構成。

キーボードは場所の矢印キー・Home/End・PageUp/PageDown、Tab循環、Escapeで図鑑に戻る操作に対応する。

以前の山道ブラウザ検証が壁際で止まった原因は、CSS百分率からの座標読み戻しによる丸め誤差。経路計画はゲーム本体の座標を参照するようにし、描画・実際の建物判定を維持したまま既存の山道往復を再検証する。
