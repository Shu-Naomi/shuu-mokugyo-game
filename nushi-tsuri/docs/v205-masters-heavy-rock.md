# v205 — 上級ライバル戦を重いロック主体に

上級ライバル戦のv204アレンジが軽く感じられるという試聴の感想を受け、主旋律とテンポを保ったまま伴奏と音色を作り直す。原曲v186の203音の音程・発音時刻・音符の長さ、152 BPM、32小節、50.526315789473685秒のループを保持する。

主旋律をオーバードライブギターに移し、同じフレーズの低いオクターブを添える。ブラスも低い音域で旋律を支える。伴奏はE2付近のパワーコードを左右の歪んだギターで刻み、低いE1付近のピックベースと合わせる。従来の疎らな高いギターの打点とピチカートを、8分の刻みと弓弦のオスティナートへ変更する。

ドラムはサンプルバンクのPowerキットを使い、バックビートとキックを強める。16〜23小節はハーフタイムで溜め、24小節からキックの細かい刻みとクラッシュ、弦を戻す。元のブリッジで省略されていた主旋律の音は足さない。

主旋律、左右のリズムギター、ベース、弦、ブラス、ドラムを別々に録音する。ギターの歪みと高域の丸め、ベースの低域、ドラムの並列コンプレッションを個別に調整する。全体の音量を上げるだけの変更ではなく、低いボイシングと刻み、楽器間のバランスを変える。ステレオとモノラルのピークに余裕を残し、余韻をつないだループとして44.1 kHz・160 kbps MP3へ書き出す。

## 再生成

v204と同じGeneralUser GS 2.0.3のピン留め済みバンク、Python/numpy/scipy、libfluidsynth、ffmpegを使う。音源のSHA-256・リビジョンと使用許諾はv204のドキュメント・素材フォルダに残す。

```sh
python nushi-tsuri/tools/arrange-masters-v205.py --soundfont /path/to/GeneralUser-GS.sf2 --wav-dir /path/to/preview
```

`assets/audio/music-v205/arrangement.json`に元の主旋律、録音・MIDIのハッシュ、楽器とバスの設定を記録する。元の作曲コードとv204の録音は保持する。新しい録音をゲームで使うのは上級ライバル戦1曲だけで、ほかの15曲はv204のバイトを保持する。

## 検証

- 既存のMIDI検証へv205の記録を重ね、実際に選曲される16曲の音程・時刻・長さを照合する。上級戦の参照203音はv204の記録とも完全一致し、残る15曲の録音ハッシュは変わっていないことを確認する。
- 16曲の全デコード、ピークと音量、曲の切り替えと大会、ミュート・復帰の既存試験を行う。
- PC・スマホの実ブラウザで上級戦を再生し、実AudioBufferSourceのループ接続を確認する。公開時は新しいMP3と楽曲メタデータ、サービスワーカーの配信バイトも照合する。
- 比較用MP3は同じ8小節を同じRMS音量に揃え、v204→v205の順で並べる。音量差だけで改良と感じないように、音色と伴奏の違いを聴ける形にする。
