# v190 水槽の魚を一匹ずつ観察

- 飼育水槽に現在の水槽番号、匹数、水質、エサ残量、操作案内を表示。魚の一覧を水槽の上に配置し、スマホ横画面では横にスクロールできる。
- 泳いでいる魚に直接タッチするか、魚の一覧または「魚を選んで大きく見る」の選択欄から一匹用の観察画面へ切り替える。小さなホンモロコにも最低44pxのタッチ判定を設ける。
- 観察画面は水槽全体の体長比を使わず選んだ魚を見やすい大きさで描画。既存の5方向ドット絵を旋回に使用。全体に戻るとヌシとの実際の体長比を確認できる。全体の拡大ボタンも残す。
- 観察だけではエサ、魚の体長、お金を変えない。別の水槽へ切り替えた時、魚を移動・引き取ってもらった時は観察を解除。選択中の魚は従来どおりセーブされ、拡大表示だけ一時的な状態にする。動きを抑える端末設定では静止した一枚で表示。
- CSS、画面スクリプト、オフラインキャッシュをv190に更新。

## 確認

ヌシと同じ水槽で小さく表示されるホンモロコを直接タッチして判読できる拡大表示に切り替え、別の魚への切り替えと全体表示への復帰を確認。操作の副作用、再読み込み、水槽切り替え、お別れ、動きを抑える設定とオフライン参照をテストした。
