# v252-52 小魚針・コイ針と狙い分け

## 変更したルール

ハリ小・中・大に、小魚針とコイ針の2種類だけを追加する。5種類とも最初から所持し、消耗しない。既存セーブの選択中の針、お金、釣果、魚のサイズ記録はそのまま残す。新しい針の選択も通常の保存・再読込と釣果の思い出に対応する。

- ハリ小：小型魚・フナ向け。基本サイズ帯が大型の魚種は、従来の餌・針の重みにさらに0.22を掛ける。魚種ごとの個別倍率と、後から登録された魚種にも適用する。
- ハリ中：標準的な魚向け。従来の倍率とサイズ抽選を維持する。
- ハリ大：コイに限らず大型魚を広く狙う。従来の倍率とサイズ抽選を維持する。
- 小魚針：タナゴ・メダカ・モツゴ・ホンモロコ・ワカサギの狙い分けを強める。フナや大型魚には不向きで、大きな個体も掛かりにくい。
- コイ針：コイを狙う倍率を上げる一方、ほかの大型魚はハリ大より狙いにくい。個体サイズを大きくする効果はない。

専用針は魚種の確定券ではない。釣り場にいない魚は出ず、餌・時間・天候・深さ・投げる距離の補正も引き続き使う。外道は残す。星湖の秘餌は引き続きハリ大だけに対応する。

## 大きさへの影響

魚種を決めたあと、サイズ階級ごとの重みに長さの補正を掛ける。補正は `1 / (1 + (階級の中点長cm / 基準長cm)^4)`。ハリ小は大型魚種にだけ基準長45cm、小魚針は全魚種に基準長18cmを使う。これは選ばれやすさの緩やかな補正であり、釣れる最大長や魚種の禁止条件ではない。元の各階級の長さの範囲、階級内の均等抽選、引き・価格の倍率は変えない。

フナ大会への影響を抑えるため、ハリ小でのフナのサイズ分布は従来どおり。小魚針では大きなフナが減るため、フナ狙いではハリ小にも役割が残る。料理の大物効果は針の補正後のサイズ重みに適用し、既存の効果を維持する。サイズ抽選は従来と同じ2回の乱数で行い、再抽選のループは増やさない。

ルアー釣りは選択中の餌・針の影響を受けない。試し釣り、既存の魚の育成、保存済みの釣果サイズも変更しない。アワセ後の針外れ・竿・ファイトの計算は変更しない。

## 比較

実ゲームの `pick` を使い、1日目08:20・晴れ・トウモロコシ・料理効果なしで、0〜1を10,000段階に分けた同じ抽選を比較した。値は候補の割合で、実際の釣り上げ成功率ではない。

| 条件 | 従来のハリ小でコイ | 新しいハリ小でコイ |
| --- | ---: | ---: |
| 湖の中層・投点50 | 1.70% | 0.38% |
| 湖の深場・投点85 | 11.25% | 2.71% |

コイが候補になったあとの巨大階級は、ハリ小で3.00%から約0.33%に減る。コイを一律に排除せず、小さなコイとの偶然の出会いは残す。

## 表示と互換性

仕掛け・道具袋の針選択、選択中の表示、保存・再読込、魚図鑑、祖父の釣り帳へ接続する。魚図鑑と釣り帳では従来の基本針に専用針を併記する。追加の2種類には既存の24×24ピクセルSVGと同じ方式で独立した原画を用意した。

変更モジュールにはv252-52のURLを付け、公開時には同じリリースのHUD・サービスワーカー・キャッシュ名を揃える。池の通路修正とは別の変更として扱う。
