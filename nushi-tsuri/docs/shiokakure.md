# 潮隠れ（v252-70）

潮風島の西礁の小さな潮だまりで、岩色の輪郭が約13秒周期でわずかに動く架空のぬし。原画・通行判定は変更しない。世界座標45,36の潮だまりを使い、45,33から下向きで到達できる。印・名前・説明のマップ表示はなく、未発見の研究ノートにも答えを出さない。

近くで4秒静かに見てから、既存のA操作で釣りを始め、投点メーターの手前0〜24で仕掛けを落とす。準備中に出現時間切れにはならない。24秒現れ、6秒隠れる周期を繰り返す。観察後に移動した場合、遠くへ投げた場合、ルアーを速く巻き続けた場合は逃げ、8秒の待ち時間後に再挑戦できる。ルアーは短く巻いて止める。星湖の秘餌は従来どおり湖専用。

クラシック方式は短い岩陰への走りをいなし、ためらう間に寄せる。テンション方式でも張力を見て操作する。強さ3.1、持久力190、専用の走りと寄せ時間を設定。既存魚の調整値は変更しない。大型の磯竿を推奨し、ルアーロッドでも最大級を取り込める。

図鑑67番、ぬし6種、一般魚61種。星降るヌシの前提3体・通常の地域別釣果・一般魚の購入一覧は維持する。海水分類、釣果、体長、金冠、専用8枚組SVG原画、7方向補間、水槽描画を共通経路に登録。遭遇状態は保存せず、既存の釣果と金冠だけを既存形式で保存する。練習・大会では遭遇しない。

輪郭は160×80の小さな透過canvasだけを既存170ms周期で描画する。背景キャッシュは無効化しない。非表示・釣り中・モーダル中には更新しない。軽減設定では輪郭を静止させても、待つことで識別できる濃さになる。近くでの5秒後の自動メニューは観察を妨げないように抑えるが、メニューボタンは使える。

- `aquarium-v184.test.cjs` と `fish-swimming-v252-30.test.cjs`: 全魚の描画、厚み、口元と針の位置、補間・キャッシュ・オフライン素材。
- `browser-shiokakure.cjs`: 本番生成HTML、1280×720・844×390・740×360、通常の観察時間と実ポインター／タッチ入力。位置と道具・最大級の乱数は明示的テストfixture。テンションは餌、クラシックはルアーを使用し、釣果保存・再読込と画像を保存する。
