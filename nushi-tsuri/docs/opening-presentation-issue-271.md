# オープニング16場面の演出（Issue #271 / v252-4）

PR #268 の台本、場面ID、会話送り、途中保存をそのまま利用する。今回の変更は `lake-intro.js` の描画と短い演出、既存画面の配置に限る。新しい画像・人物・犬・マップは追加しない。

## 演出

- 家と帰郷は既存の背景を広く見せる紙芝居。絵は縦横比を保って全体を収め、縦に長いPC画面でも三匹を切らない。手帳はドットの紙面・研究記録・魚のスケッチを描き、開く動きと軽い頁送りを加える。
- 主人公とサムは既存の立ち絵・歩行スプライトを使い、接近、向き変更、主人公の一歩後退、小さな間で押し問答を表す。
- 三匹は既存の歩行画像と足元の基準で画面右から登場する。現在のお気に入り犬が先に駆け寄り、次の場面で主人公の裾へ寄り添う。残る二匹も同じ画面に残る。名前・性別・お気に入りは既存スロットの表示用データを参照する。
- 一場面の動きは最長1.6秒、描画は最大12回/秒。会話送りやスキップに待ち時間を設けない。モーション軽減時は最終構図を表示する。

`pose()` は時刻を受け取って座標を返すだけで、乱数・ゲーム時計・状態・保存に触れない。`present()` が一つの短いRAFを管理する。頁変更・終了・スキップ時にRAFと画像読込コールバック、可視性・モーション設定のリスナーを解除する。背景タブでは動きを終了し、復帰後に遅れた動きを流さない。画像が遅れて届いても終了した場面を描き直さない。

## 保存と既存機能

保存形式は変更しない（`lakeStory.version=2` / `introVersion=2`）。16場面の台本文字列も変更しない。保存済みの `introStep` から再開し、その場面の短い見た目だけを再生する。フレームや座標は保存しない。旧セーブの扱い・別スロット保護・読み返し・自由行動への戻り位置は既存処理を利用する。

犬の内部ID・育成・時刻・所持品・釣り・水槽・黄金フナ・60魚種・真エンド条件は変更しない。PR #270 の入口判定、餌なしのルアー例外、準備／仕掛け画面から戻る処理も変更しない。
