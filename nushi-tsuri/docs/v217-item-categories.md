# v217 — 持ち物とお店の分類

道具袋の「持ち物」を九分類へ整理した。餌、ルアー、食べ物、食材、犬のおやつ、犬のおもちゃ、釣具・パーツ、コレクション、奉納品を切り替える。分類名の数字は、個数の合計ではなく所持している品の種類数。食事効果は食べ物欄、トロフィーはコレクション欄に置く。装備・タックルの上位タブと飼育水槽の入口を保つ。

横画面スマホでも分類と一覧を左右に置き、それぞれ独立してスクロールできる。分類ボタンは44px以上。選択中の色、キーボードのフォーカス、aria-pressedとaria-controlsを用意し、未所持の犬のおもちゃや収集品には案内を表示する。閉じて開き直すと同じ分類を表示するが、分類の選択は所持数やセーブ形式に追加しない。

食材欄には魚種別の切り身・山菜に加え、既存レシピで使う貝、小エビ、木の実、キノコなどを掲載する。餌や犬のおやつと共用する品にはその用途を記す。同じ保存先から数を読み、二重に付与・消費・移動しない。料理の材料一覧から共用する食材を集める。

サムの店は「釣具」の中を餌・釣り竿・ルアー、「装備・雑貨」の中を手装備・犬のおやつ・犬のおもちゃに分ける。各分類に販売する品の種類数を表示し、価格と在庫は従来どおり品物に表示する。餌のセット数、購入済みの竿・手袋・おもちゃの制限、ルアーの購入、購入後の選択分類を保つ。

八百屋は食べ物と奉納品を分け、個数指定は分類を切り替えても継続する。食堂は食べ物・料理を作る・作り置き、家と釣り宿の台所は料理を作る・作り置きに分ける。販売していない食材や収集品を新商品として追加しない。単一用途の舟具屋と魚屋の会話には分類を増やさない。

HUDはv217。新しいitem-categories.cssを217-1で読み込み、オフラインキャッシュに追加する。sw.jsは217-1。魚の原画、旋回、水槽背景、紙芝居、魚種とサイズの抽選、料理の効果、二つのセーブの既存仕様を保つ。

検証はitem-categories-v217.test.cjsと実ブラウザのbrowser-v217.features.cjs。分類の切り替えだけでは資源が変わらないこと、食べ物と食材の分離、共用する食材の消費、個数指定の購入、購入済みおもちゃの重複防止、手袋の装備、保存と再読込を確認する。PC1280×720とタッチ操作の横画面スマホ844×390で、一覧と分類の独立スクロール・表示範囲・44pxの操作範囲・画面回転を確認する。公開検査は新CSSもmainとバイト単位で比較する。
