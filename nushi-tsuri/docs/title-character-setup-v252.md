# タイトルと初回キャラクター設定 — v252-1

基点main: `a2b1196a68f2f516d17d2c949129917dcdaf4dd6`（PR #266）。「星降る湖」から「はじめから」「つづきから」「設定」へ進む。新規は空きセーブ選択 → 主人公の性別・名前 → 犬3匹の比較 → 確認 → 冒険開始。画面内に「名前と犬は後からでも変更できます。」を表示する。

`title-flow.js` は画面遷移と未保存の下書きだけを持つ。名前の正規化・1〜12書記素の検証・既定名・犬IDは PR #266 の `ShuPlayerOptions` を共用する。IME変換中のEnterやsubmitでは進まず、空欄や13文字以上は案内して停止する。確認表示は textContent。犬の初回改名は追加せず、既存設定から後で変更する。既存の主人公・犬の画像を切り出して表示し、原画を変更しない。

## セーブと互換性

保存フィールド・キー・mapVersion・petLife.version=6 は変更しない。主人公 `playerName` / `avatar`、お気に入り `dog`、犬名 `dogNames` を既存の冒険データへ保存する。内部IDは `shuu` / `riku` / `grey`。選択しなかった犬も従来の初期化で育成対象として残る。続きからでは、URLに渡された初期名・性別・犬より保存済みの値を優先し、`dogFollowing=false` も維持する。

- タイトル閲覧・下書き・戻る・キャンセルでは冒険JSONや最後に遊んだスロットを書かない。下書きはページを離れるまでスロット別に保持する。
- 新規開始は空きスロットのみ。2つとも使用中なら既存冒険か設定へ案内し、上書き・自動削除を行わない。削除は既存設定の内容確認＋チェック付き確認のまま。
- 保存直前にも `ShuSaveSlots.writeNew` で空きを再確認する。下書き中に別タブで保存先が埋まった場合や、スロット移動後の `newGame=1` 到着時に先客がいる場合は止める。localStorageの最終読み取りと書き込みは同期的に行う。
- 続きからの保存がタイトル読込時から変わっていれば再ロードし、最初の保存も `writeIfUnchanged` で読み取ったJSONとの一致を再確認する。破損・アクセス不能データは上書きしない。
- 読込時には存在した冒険が別タブで削除された場合も、新規開始時に再ロードして空の状態から初期化する。削除済み冒険の所持金・釣果・育成や任意項目を新しい冒険へ引き継がない。新規冒険の犬名は共通の既定名を使い、タイトルの設定で編集した後に削除された冒険の犬名も残さない。
- 最初の保存失敗時はタイトルを維持し、ゲーム操作・追いつき繁殖・pagehideの自動保存を開始しない。準備済みの黄金フナ抽選種を保持して再試行する。成功後は従来どおり種の保存確認 → 繁殖同期 → 導入の `introPending` / `introSeen` へ進む。
- 既存の `ShuSaveSlots.launchUrl` / `launchSettings` を共用する。追加のURLフラグ `newGame=1` は新規の別スロット移動に限り使用し、到着時に他の起動用パラメータと一緒に除く。

設定画面・音量・文字速度・命名変更は共通の既存オプションを開く。端末共通設定とスロット別の人物情報を分離したまま、設定画面には対象セーブを表示する。タイトル上のキーボード入力は背後の世界へ送らない。
