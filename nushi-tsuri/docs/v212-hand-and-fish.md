# v212 — 撫でる手とホンモロコ・アユ

撫でる手の指が下へ突き出し、頭をつかむ形に見えていた。手の甲から見た右手へ描き直し、四本の指を曲げて額に寝かせ、親指を手の横へ添えた。手首と袖は右上からつながる。近づく・撫でる・浮かせて戻る・退出する動き、犬の足位置、まぶた、報酬は保つ。

v208の湖原画はホンモロコとアユにもシロギスのような二つの大きな背びれを描いていた。両種は既存の専用原画へ戻し、共通の描画関数で泳ぎ・七段階の旋回・口開閉を扱う。近い正面方向の二段階は専用の斜め原画を横方向へ投影する。ホンモロコは銀色と一枚の大きな背びれ、アユは黄斑と一枚の大きな背びれ・小さな脂びれで見分ける。シロギスを含むほかの22種の原画は変更しない。

原画PNGの書き換えや画像生成による新しい原画の導入はない。生成は失敗したため、残っていた原画をそのまま再利用した。原画の複数画像を読み終えてから描画し、別画像の座標を誤って切り抜かない。釣り・釣果・図鑑・水槽は同じ入口を使う。サービスワーカーと描画モジュールの版を212-1へ更新した。

## 確認

- 三匹の原画、足位置、手の接触、瞬き、食べ切ってから手を引く動作を確認。
- 24魚種の泳ぎ・旋回・開口で輪郭が欠けないこと、尾が動き口元が固定されることを確認。
- 実際の画像の輪郭から大きな背びれを数え、ホンモロコ・アユは一つ、シロギスは二つと検査。魚種名のラベルだけで判定しない。
- 読み込み中の原画で既存の描画を消さないこと、専用原画をオフラインキャッシュへ含めることを確認。
- GitHub Actionsで全単体検査とPC・横画面スマホの実ブラウザ検査。公開時は配信ファイルのバイト一致と同じブラウザ検査を行う。

形態の確認資料：国立環境研究所の[ホンモロコ](https://www.nies.go.jp/biodiversity/invasive/DB/detail/50560.html)、広島市農林水産振興センターの[アユ](https://www.haff.city.hiroshima.jp/info/suisansc/fish/sweetfish/)。
