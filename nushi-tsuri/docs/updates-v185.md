# v185 星のカプセルガチャ

大型更新の第2弾。竿みくじの単発と10連に、色付きのカプセルが落ちて弾み、二つに開く演出を追加した。

| 景品 | カプセル |
| --- | --- |
| 星見の竿 | 輝くオレンジ |
| ワンコのおもちゃ・おやつ | 青 |
| 普通の釣りエサ、ルアー・竿パーツ・図鑑収集品 | 白 |
| お祝い金 | 金 |
| ぬしエサ | 紫 |

- 10連は一個ずつ開けて進む。開封状況は10枠のトレーで表示。
- 「まとめて開ける」で全結果へ進める。結果は時間で消えず、自分のペースで読める。
- 単発の直近結果と前回の10連結果を保存し、閉じた後や再読み込み後も神社で見返せる。
- 景品は抽選直後に全件受け取り・保存。開封、スキップ、閉じる、再読み込みで再抽選や再付与をしない。
- 排出時の鈴、開封時の当たり音、大当たり音は既存音源を使用。ミュートと画面非表示を尊重し、途中終了後の遅れた音を止める。
- 演出中の背後のボタンを無効化し、キーボードフォーカスを演出内に保つ。動きを減らす設定では移動・開封アニメーションを省略。
- ドット調のカプセルはコード内のSVG。追加の画像生成・外部音源・依存パッケージはない。

抽選確率と重複景品の補償は従来のまま。v184以前の文字だけの10連履歴も引き継ぐ。
