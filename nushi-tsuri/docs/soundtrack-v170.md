# v170 音楽と環境音

マップは季節ごとの和風BGM、建物は場所ごとのBGM、キャストは環境音に切り替える。

| 場所 | オリジナル曲 |
|---|---|
| 春のマップ | 春・花びらの小径 |
| 夏のマップ | 夏・青葉と川風 |
| 秋のマップ | 秋・茜の水面 |
| 冬のマップ | 冬・雪待ち灯り |
| 自宅の庭・室内・台所 | ただいま、相棒 |
| サムの店 | サムの釣具日和 |
| 星占い神社・水守りの社 | 星を結ぶ祈り |
| 釣り宿 | 水守りの宵布団 |
| 八百屋 | 朝採れの籠 |
| みなと食堂 | 湯気の向こうで |
| 港の魚屋 | 朝市の銀うろこ |
| 舟具屋 | 港の舟支度 |

12曲とも独自の旋律と伴奏を持つ16小節のループ。琴・三味線をイメージした減衰する弦の倍音、笛の息成分、控えめな打楽器をプログラムで合成した。既存曲・楽器の録音サンプルは使用していない。作曲データと再生成スクリプトは `tools/compose-soundtrack-v170.py`。MP3は32kHzステレオ、音楽80kbps、鳥の声は可変ビットレート。

キャスト準備・投げる・待つ・アタリ・水中の全段階でBGMを止める。砂浜は従来の波、川は従来のせせらぎ。湖と試し釣り池には小鳥の合成音、船着き場には海鳥を模した合成音を水音に重ねる。鳥は間を空けて鳴き、夜と小雨では小さくなる。水中では鳥を止め、従来の水中・操作SEを使う。v169の雨音も継続する。

音楽は解除済みの既存AudioContextにつなぐ。再生用ループは1本、出入りで短くフェードし、同じ場所に戻ると続きから流す。季節・部屋・キャスト・ミュートの変更後に古い音楽の読み込みが完了しても再生しない。デコード済みキャッシュは最大2曲。消音・非表示・画面離脱で停止し、再開時は既存の音声解除処理に従う。水音のプリロードも一度にして、ボタン操作のたびに再読み込みしない。

確認：音楽の選択、読み込み競合、ループ再開、消音、実際の画面遷移、鳥・水音の切り替え、全14音声の完全なデコード、既存の釣り・天気・オフライン動作を合わせた24テストが成功。音量とループの端の波形も数値確認した。試聴用の `soundtrack-v170.html` では季節を進めずに12曲と鳥の声を再生でき、同時再生を防ぐ。
