# v244：魚の抵抗を見て引く

ぬし釣り式の下のテンション窓をなくし、魚の動き・糸・短い合図で駆け引きを読めるようにする。右へ逃げ、左の水面へ取り込む向き、ルアーで追ってきた同じ個体へのアワセ、ゲージ式の表示は継続する。

- 下の枠はぬし釣り式のファイト中だけ非表示。魚名・残りメートル・操作の合図を左上に二行で出す。ゲージ式とキャスト前は既存の窓を使う。
- 逃走は魚の特性と泳ぎの強弱で加速し、尾の動き・水の跡・背景の速度も合わせる。右端に着いても背景が遅く止まることを防ぐ。
- 引ける隙が終わると、横顔から斜め前への既存の魚絵を往復して激しく顔を振る。魚の実際の姿勢から針・糸の接点も追従する。
- 顔振りを初めて表示してから1.44秒後に逃走へ移る。最初の0.72秒は離すための猶予。抵抗の後半や逃走中に引き続けると糸が傷み、強い竿でも切れる。練習では切れない。時間は本作の調整値で、原作の秒数・内部計算を再現したとは扱わない。
- 引ける長さと逃走時間を各ターンで抽選する。隙を見て最初に押せば、その回の長さを確保する。押し直して抽選し直したり締切を継ぎ足したりはできない。引ける隙と走りを交互にし、ヌシの相の変化は現在の隙を打ち切らず次の逃走に予約する。

| 特性と主な魚 | 引ける長さ | 逃走時間 |
| --- | --- | --- |
| 穏やか：モロコ・フナ・タナゴなど | 2.8〜6.4秒 | 1.8〜3.0秒 |
| 素早い：アユ・ヤマメ・ヒメマス・アジなど | 1.6〜4.4秒 | 2.1〜3.8秒 |
| 重い引き：コイ・ナマズ・マダイなど | 2.2〜6.0秒 | 2.4〜4.4秒 |
| 急襲：バス・ライギョ・スズキ・ウナギ | 1.8〜5.0秒 | 2.1〜4.1秒 |
| 底で抵抗：ヒラメ・カサゴ・アイナメなど | 2.0〜5.6秒 | 2.0〜3.8秒 |
| ヌシ各種 | 1.6〜5.2秒 | 2.6〜4.8秒 |

開始時にAを待つ緩みは最低2.4秒。表は最初の正しい入力から確保する時間であり、毎回同じ秒数ではない。実際の寄せ量には竿の力・魚の引き・距離が効く。背景の動きは個体の再抽選や所持品・釣果・実際のメートルを変更しない。

検証は`fish-resistance-v244.test.cjs`、既存のv228・v242・v243回帰、および`node browser-v244.evidence.cjs`。ブラウザはPC1280×720とタッチ844×390・820×366/DPR1.875で両方式を通す。ぬし釣り式の操作判断は表示される糸の緩み・顔振り・逃走だけを使い、隠したテンション値は読まない。600msの反応遅れを入れた自然な取り込み、保存再読込、別の自然なアワセから押し続けた場合の糸切れ、釣果が増えないことも確認する。携帯実機の操作感は別確認。
