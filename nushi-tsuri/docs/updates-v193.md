# v193 スマホ横画面の全画面表示

Android横画面の右側に見える薄い帯は、戻る・ホーム・履歴の3ボタンを置く端末の操作領域。ホーム画面から起動した「星降る湖」は、従来の `standalone` モードではその操作領域が残っていた。

アプリのマニフェストを `fullscreen` に切り替え、インストールしたゲームの起動時にシステムバーを隠して画面を使う。通常のブラウザタブの表示とゲームのセーブ形式には変更なし。全画面中も、画面の端からスワイプするとAndroidの操作領域を一時的に出せる。既存のホーム画面アプリへの反映はブラウザ側のマニフェスト更新に依存するため、公開直後に変わらない場合は一度アプリを閉じて再起動する。オフラインキャッシュもv193に更新した。
