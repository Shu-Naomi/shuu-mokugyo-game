# v189 飼育魚の成長を1〜5cm/日に

実際に遊ぶと、従来の1日0.10cmでは稚魚から成魚まで長すぎたため、飼育の成長速度を変更する。

| その魚種の最大体長 | 1回のお世話で翌日に伸びる体長 |
| --- | ---: |
| 50cm以下 | 1cm |
| 50cm超〜100cm | 2cm |
| 100cm超〜150cm | 3cm |
| 150cm超〜200cm | 4cm |
| 200cm超 | 5cm |

- 1匹につき1日1食、水質40%以上で翌日成長する。数日飛ばしても1食で育つのは1日分だけ。同じ日に再読み込み・画面再描画しても二重に成長しない。魚種の最大体長で止まる。
- 小さなモロコの稚魚（6cm）は1日1cmで、2日の給餌後に販売時の成魚体長7.50cmを超える。ヌシのような大型魚も1日最大5cm伸びる。
- 以前のセーブに記録された個体の体長・お世話の日付・★・世代を保持し、次の有効なお世話から新しいペースを適用。既存の繁殖・買い取り・品評会の判定と水槽の縮尺は維持。
- エサをあげた時の案内と水槽の魚ごとの成長ペースを更新。飼育水槽・ガチャ・音などを含むオフラインキャッシュをv189に更新。

## 検証

魚種の大きさによる5段階、日付飛ばし・同日再計算・最大サイズ、旧セーブと水槽UIの成長表示、稚魚の育成と買い取り、オフラインキャッシュ参照を確認する。
