# v200 — 仕様v0.6の実装

釣りは「投点 → 誘い／前アタリ → 食いつき → Aでアワセ → 選んだ水中ファイト」の共通工程になった。

- 道具袋の「タックル」でゲージ式／ぬし釣り式を選択。初期値と古いセーブはゲージ式。方式・竿・強化値は投げる時に固定。
- ぬし釣り式では右へ走る魚をいなし、糸のたわむ休息時にAで寄せる。左上の水面で取り込み。魚種別の泳ぎ、ヒラメの砂底、跳躍、ヌシの三段階は維持。竹の竿ではヌシを取り込めない。
- サムがルアーロッド（25000円）、潮騒の竿（65000円）、海王の竿（120000円）、銀のスプーン（600円）を販売。スプーンは繰り返し使い、失敗だけでは紛失しない。
- スプーンはAで誘い、興味を示した一匹が先に現れる。食いついたら一度Aを離して押し直す。アワセの猶予は1.5秒（練習は2.8秒）。アワセ入力は巻き操作と分けた。
- 投げた時だけエサ・時間・大会投数を一回消費。スプーンはエサを消費しない。隠れた画面では反応時間とファイトを停止し、復帰時に押しっぱなしを解除。
- 星見の竿の重複は本数として保存。道具袋で余分な一本を12000円で売る、一本を重ねて＋5まで強化する、保管するを選べる。最後の一本は残す。既に変換されたパーツは維持し、竿を遡って創作しない。

飼育水槽とコンテストも同じ保存データで続けられる。

- 魚のエサやり＋6XP、水換え＋4XPは各個体・一日一回。Lv.1〜20、次のレベルまでの経験値を表示。既存の体長・★・世代・世話日数を維持し、過去の世話日数から初期経験値を設定。
- 品評会はレベル35点、成長と★25点、元気25点、水質15点。上級は長く育てる目標。
- 健康な同種の成魚の雌雄を同じ水槽で3日世話すると卵を産む。草際／砂利の卵を描画し、魚種に応じ2〜4日で孵化。卵一組で稚魚一匹の枠を予約。親の移動後も水の種類と予約を維持。孵化時に通知。
- なつき度は既存の数値を保持し、今後の増加速度だけを抑制。初級・中級には毎回違う村人、犬名、犬種、能力。上級にはリアオ、アスアル、ダンサーの相棒が参加。
- 入場 → 実演 → 観客審査 → 順位発表。なつき度・魚は観客評価±5点。芸はお手／おかわり／チンチン／伏せ／ハイタッチをプレイヤーが一つずつ指示し、習熟度で成功判定。
- 芸の犬は既存の精密スプライトを使い、実際の前脚を動かす。成功は歓声と観客の動き、失敗は困り顔の動き・汗・ぐるぐる吹き出し。軽減モーション設定では動きを抑える。
- 参加時に参加費と相手・判定乱数を保存。途中で閉じる・再読み込みする場合も舞台から再開し、参加費・賞金は一度だけ。旧コンテスト結果も読める。
