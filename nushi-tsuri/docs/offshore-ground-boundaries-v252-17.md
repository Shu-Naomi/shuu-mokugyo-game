# 潮風島：道の外へ入れてしまう判定の再修正（v252-17）

直美の実プレイ画像で、休憩所から東の分岐へ向かう道の北側の植え込みに立てていた。v252-16では通れる地点の接続を確認していたが、道を外れようとする入力の検査が不足していた。

## 原因と修正

旧中心線の `(144,52) → (151,47) → (156,46)` は、原画の道より北にあり、植え込みと岩の下を通っていた。半幅3の通行域がそのずれを広げていた。西側の旧 `(88,60)` と灯台側の旧 `(151,44)` も草木・岩の上だった。

原画上の地面に合わせ、休憩所から東の分岐、西の道、灯台への階段、船着き場への曲がり道と砂浜の階段の中心を引き直す。半幅を地面に応じて1.15〜1.6にし、休憩所前の床を狭める。主人公の既存の足元アンカーと元画像を使い、原画・キャラクターの描画は変更しない。

報告地点の近くの道 `(143,56)` は通行可能、北側の植え込み `(143,52)` は通行不可。旧版で許可されていた独立した7つの障害地点を旧モジュールで確認し、修正版ではすべて拒否する。期待地点は `offshore-collision-fixture.cjs` に原画から記録しており、判定の線や幅から計算しない。

## 操作とセーブ

道10地点・障害18地点に加え、7か所の道端で外向きに連続入力し、画像上の境界を越えないことを確認する。単体では実際の `move()` を各10回、ブラウザでは実方向ボタンを各5回入力する。道の中心だけを経路探索して通れたことを成功条件にしない。

旧版の植え込み上にあるセーブは既存の近傍復帰で近い道へ戻す。報告地点・東の分岐・西の森からの復帰と、正しい道上の位置保持、保存再開、所持金739575円・エサ128・他スロットを検査する。セーブ形式、往復800円、帰港、魚と水槽、所持品の仕様は変更しない。
