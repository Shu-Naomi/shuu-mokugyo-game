# メバルと前の魚が重なる表示の修正（v177）

ホンモロコ・フナ・コイ・ナマズ・ボラなどを描いた共用Canvasには、画像の読み込み待ちに使うCSS背景が残っていた。続いてメバルを描くと、その透過部分から前の魚が見え、口や尾などが重なる。水中の釣りと釣り上げ画面の両方で再現した。

メバルへの切り替え時はCanvas自身の背景を透明にし、前の魚の描画と古い読み込み要求を解除する。メバルのアニメーション中は、次のフレームが読み込まれるまで直前のメバルを維持する。ほかの魚も、読み込みが終わったら不要になった背景を取り除く。魚の画像ファイルや釣果の処理は変更しない。

`tests/fish-render-transitions.test.cjs` で、全魚種からメバルへの切り替え、最初のフレームの読み込み待ち、次フレームの待機中の表示維持、遅れて読み込まれた前の魚による上書き防止を水中・釣り上げの両方で確認する。同じテストは修正前には失敗する。実際の画像をゲームの描画処理に渡した修正前後の比較でも、余分な魚の輪郭が消えることを確認した。

釣りUIと針の同期、水槽、前回の港の通路と会話、オフラインキャッシュの回帰24件と、今回の追加3件の計27件が成功。画面のバージョンとキャッシュをv177へ更新する。
