# 犬のお世話と湖畔の釣り宿 UI（v251-5）

対象はワンコずと遊ぶ画面と、既存ID farmhouse の釣り宿だけ。基点 main は 5dfb91ff398dbccad7cfce0776d595c252014a30。参照は共有された10414.png（宿）・10416.png（犬）。画像自体はリポジトリへ追加しない。

## 変更

- ナデナデの手を、四本の指・一本の親指が一つにつながる小さい輪郭へ変更。腕・手首も細くし、頭上での往復を18から10座標へ抑えた。演出だけ3.6秒に延ばし、日ごとの回数・懐き度効果・保存処理はそのまま。
- 犬原画・食事・芸・道具は変更なし。犬の表示、状態表示とスクロールできる道具一覧、44px以上の固定操作欄を別の領域に置いた。ナデナデ案内文も画像の外へ出し、頭・手を隠さない。BESTは見出し行で確認できる。
- 宿だけに compact-inn を付け、料理タブ・案内・退出を一列にまとめた。料理一覧と選択中の効果/素材/作成を隣接させ、宿泊ボタンは説明付きの独立した行へ配置。PCは幅1100px・高さ420pxまでの中央ウィンドウにし、文字や操作を縮めずに余白を減らす。
- 宿の内装キャンバスと重なり用キャンバスを同じ枠へそろえ、原画全体を contain で表示。会話文は幅全体の下段へ移し、行数で切り捨てない。長文は会話欄内で最後まで読める。
- 既存の原画PNG、釣り・魚種・水槽・繁殖・移動判定、料理/宿泊の効果とセーブ形式は変更しない。キャッシュとcompact-ui参照だけ251-5へ更新。

## 検証と根拠

- 関連の手元41件と追加3件が成功。料理の消費・翌朝06:00・旧セーブ、宿から他施設へのUI復元、犬の既存日次処理を確認。
- native canvasで犬3匹×217コマ（3.6秒を60Hzで標本化）の計651コマを実描画。手の肌領域は一つにつながり、輪郭が変形せず、目元へ落ちないことと移動の連続性を検査。元の犬原画を使う。
- care-inn-frame-checks.cjs は全コマPNG・全コマ一覧・代表ポーズを保存できる。確認用PNGはCI artifactへ保存し、ゲーム資産へ混ぜない。
- 実ブラウザは1280×720、タッチ844×390、タッチ820×366/DPR1.875。各画面で651コマの再描画検査、犬3匹の実時間のナデナデ、下端の4種類の道具までスクロール/タップ、遊ぶ・保存再開、宿の料理選択/作成/宿泊/退出/保存再開を確認する。動画も記録する。
- 成功・失敗・準備中の検査を区別し、対象commitと最新結果はPR本文と引き継ぎへ記録する。ナデナデ案内文と表示枠が重ならないこと、最後のおやつも操作欄へ隠れないことを実ブラウザで確認する。
- 従来の成功記録はPR259本文と村改修資料に保持。今回index/compact-uiが変わるため、この2画面のブラウザ検査は従来の成功で代用しない。無関係な検査の無差別再実行は行わない。

魚屋や追加マップはこの変更の対象外。
