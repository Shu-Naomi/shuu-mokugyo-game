# v195 沿岸釣りと舟の位置を調整

- 白砂の小島と岩礁の小島で、それぞれ独立した釣り画面を表示。港の建物と桟橋を沿岸の背景に出さない。
- 釣り準備から投点決定まで小島の釣り場情報を保持し、シロギス・アイナメ・マダイを含む固有の魚から抽選する。
- カヌーとタライの地図上の表示を小さくし、各桟橋の乗船地点を水側へ調整。舟が港の桟橋の上を通ることも防ぐ。
- 沿岸で海と舟の描画を隠していた地図の表示指定を修正。緑の下地だけが見える状態を防ぐ。
- ファイト中のBで張力を大きく下げる代わりに魚との距離が少し戻る。Aを離すだけなら従来どおり巻きを止める。
- 既存のセーブデータと所持している舟はそのまま使える。
