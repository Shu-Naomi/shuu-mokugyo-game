# 峠の沼の横断橋と釣り広場 v252-50

2026-11-05、狭い道と当たり判定を直し、沼を横切る橋と中央の憩いの釣り場を作り直す依頼に対応。既存の沼の森・葦・岩場・水の色と細かなピクセル画を参考に全体を一枚で新作画した。原画は1671×941。公開用WebPは同じ寸法で変換し、道路・床・柵・岸を完成画から独立して測定した。

## 移動と釣り

- 周回路の基本幅を約6.2から10.2ワールド単位へ拡幅。南西の入口、葦守りの家、東の湿地への道を接続する。
- 西岸と東岸を横断する橋の床は幅13.5単位。中央の広い木のテラスには腰掛け、籠、灯りがあり、通り道を塞がない。
- 橋の柵、支柱の足元、腰掛け周りは通れない。床以外の沼も通れない。移動は既存の四分の一単位の掃引判定で検証する。
- 中央テラスの上下、柵が開いた2か所だけが橋上の釣り口。上側では上向き、下側では下向きでA。橋の通行部分、柵越し、広場中央からは投げられない。他地域の橋も従来どおり釣れない。
- 既存の岸釣り、魚種、餌・針・距離ごとの釣り分け、釣果記録を維持する。休憩による回復や時間送りは追加しない。

## 既存データと住人

地域ID `mountainMarsh`、出入口の行き先、セーブキー、釣り場IDは変更しない。旧道が水や柵になった位置の保存は既存の近隣安全位置補正で復帰する。お金、餌、釣果、装備、犬との関係、依頼進行はそのまま。葦守りの家の入口は同じ座標に維持し、2人の住人の歩く範囲を新しい乾いた道へ合わせた。
