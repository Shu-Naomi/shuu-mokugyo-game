# v252-25: 淡水・海水それぞれの水槽風景

海水槽にサンゴと岩、淡水槽に水草と流木の精密なドット背景を用意した。魚が主役になるよう中央を広く空け、金色・白色個体や小魚の輪郭が分かる落ち着いた色にする。装飾は両端と底の隅に集め、底中央も低密度とする。背景には魚・文字・UIを描かない。

- 淡水: `assets/aquarium-fresh-v252-25.webp`。水草、流木、苔岩、小石。
- 海水: `assets/aquarium-salt-v252-25.webp`。自然な控えめの色のサンゴ、礁岩、白い砂。
- 通常の空き槽: 従来の `assets/aquarium-interior-v214.webp` を維持。
- 魚がいなくても卵の水種を使用。淡水・海水ぬし槽は空でも固定の水種。

既存の `tankWater()` に基づく表示属性だけを全体・一匹観察の双方へ渡し、CSSが背景を選ぶ。セーブ項目・水種の同居制限・繁殖・成長・魚の絵・サイズ・泳ぎを変更しない。魚移動や水槽切替、拡大/解除で既存の再描画を利用する。新しいタイマーや毎フレームの計算は増やさない。既存の泡・水面光・水質の濁り・ガラスを保持し、背景は `z-index:0` / `pointer-events:none`。

新画像は1672×941、RGB、ロスレスWebP。原画像の画素を変えずPNGから符号化した。淡水1,790,724バイト、海水1,640,342バイト。両方の合計約3.27MiBが追加キャッシュとなる。独立した版付きファイルを使用し、既存背景を上書きしない。

- 既存の育成・繁殖・水槽操作・一匹観察17件成功。
