# 魚屋右側の通路と会話欄（v176）

魚屋前の座標171,107から右へ進むと、175,107の石畳を海と判定して止まっていた。北側の魚屋の建物判定にも接するため、サムの店へ向かう角が通りにくくなっていた。

港の岸壁の角を、原画に描かれた石畳に合わせてx=174から179まで修正。4単位の移動で角を曲がり、魚屋の右からサムの入口へ往復できる。隣の海面・船・建物の内部は引き続き通れない。

NPCの会話は、画面下に左側の四角い顔画像と右側の横長のメッセージボックスを並べる。顔は既存の会話ポーズから描画時に拡大表示し、原画ファイルはそのまま使用する。名前と短い順位表示、セリフ、会話用ボタンだけに整理し、重複していた終了ボタンを削除。マップのスクロールに影響されず、画面の幅と高さに合わせて大きさが変わる。

A・Z・Enterで次のセリフ、B・X・Escapeか「会話を終える」で終了。ボタンにフォーカスしている場合のEnterは、そのボタンを通常どおり操作する。会話中は移動・キャストを開始せず、エサ・時間・大会の釣果を消費しない。

検証対象：全16通りの移動グリッドで通路を往復してサムの店に入る、途中のセーブから再開、海面と建物の境界、会話のA/Bとキーボード入力、既存の大会・移動・釣りUI・音・天気・ガチャ・オフライン動作。

大会の参加費・賞品などの第3段階は、この修正後に別途進める。
