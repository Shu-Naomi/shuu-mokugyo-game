# v202 — 峠の池・沼、地下湖、地域のヌシ

渓流の北の峠から「峠の池」、その北東の尾根から「峠の沼」へ進める。岩窟入口から地下湖へ入り、各地域で釣りをして来た道へ帰れる。新しい地域で保存しても同じ場所から再開し、移動で体力・持ち物・釣果を失わない。

ユーザーが決めた条件は、渓流の通常魚を全部釣ると告知なしで架空のヌシに出会うこと、沿岸・地下湖・最後の巨大なヌシを別魚にすること、物語は最後に追加すること。以下の具体名・残る地域の条件・竿の強さ・夜間条件は今回の実装で選んだもの。

| 魚 | 条件と場所 | 竿の強さ |
| --- | --- | --- |
| 渓流のヌシ | 渓流マップの川・池・沼で通常9種を釣った後、川の深い淵 | 2.4以上 |
| 沿岸のヌシ | 小島で通常10種を釣った後、小島の沖の深場 | 3.0以上 |
| 地底湖のヌシ | 地下湖でフナ・コイ・ナマズ・ウナギを釣った後、深場 | 3.4以上 |
| 星降るヌシ | 上記3匹を釣った後の夜、星降る湖の深場 | 4.0以上 |

村や峠の先の別マップで同じ普通魚を釣っても、渓流マップの達成に加算しない。地域別の成功釣果を保存し、試し釣り・講習・飼育魚の誕生は除く。v201の記録は最後の釣果に山・小島の場所が明記されている魚だけを一種類として一度だけ引き継ぐ。地域が分からない古い釣果を推測しない。通常魚を揃えても解放テロップを出さず、次の釣りの候補にヌシを加える。

旧ID `nushi`（星湖のヌシ）の釣果・飼育・秘餌を保持する。最後のヌシが出現できる夜には星湖秘伝の餌が最後のヌシを選び、それ以前は従来の星湖のヌシを選ぶ。山の池・沼・地下湖では秘餌の投げ込み前に止め、餌・体力・時間を消費しない。新4魚は両ファイト方式に対応し、サイズ・釣果・金冠・図鑑をそれぞれ持つ。展示水槽の泳ぐ速さ・上下動・水深も4匹それぞれに設定する。架空の魚と明記する。通常の飼育魚として販売・繁殖しない。

完成画像に合わせて岸と道を計測した。村の施設・採集・NPC・港を山へ重ねない。背景キャッシュにマップ名を含め、同時刻で往復しても前の絵を残さない。地下湖は鉱石の光で固定し、夜に岸を暗くしない。

## 検証と復旧

追加試験は4マス移動の連続、入口と帰り道、保存と再開、釣果の一回記録、無告知の達成、深場限定の出現、最後のヌシの夜間条件、秘餌の従来動作、両方式の竿の強さと取り込み、別項目の図鑑、飼育・繁殖の除外、全64魚ポーズ、釣果カード、実背景3点、背景切替、地下湖の夜の明るさ、オフライン用素材登録を確認する。既存の村・犬・水槽・舟・大会も含めて `npm test` を実行する。

作業環境の接続が全体試験中に切れたため、v201の確定Gitツリーから保存済みの変更を復元し、生成PNGをGit blobへ退避した。GitHub Actionsで復元した実装を全体試験し、通過したコミットだけを公開する。断線前の結果を全体試験の完了とは扱わない。

物語の追加は、地形と地域の釣りが揃った後の最後の工程として残す。
