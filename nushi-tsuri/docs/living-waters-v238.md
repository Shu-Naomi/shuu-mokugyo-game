# v238 水辺の魚と暮らし

通常の魚を6種追加し、全45種とした。カワムツ、ヘラブナ、ヒメマス、マハゼ、サヨリ、マサバは通常の餌・ハリ・距離による抽選、両ファイトモード、釣果記録、図鑑、飼育水槽、セーブ復元へ接続する。既存番号とセーブ形式は保持。新しい価格・サイズ階級・抽選率はゲーム用の調整値。

|魚|主な釣り場|狙い方|
|---|---|---|
|カワムツ|民家川・星見渓流・水郷の小川|川虫、ハリ小、岸際|
|ヘラブナ|湖・峠の池・水郷の睡蓮の池|練りエサ、ハリ中、中層|
|ヒメマス|峠の池|川虫、ハリ中、中層〜深場|
|マハゼ|潮見浜・港・白砂の小島|ミミズ、ハリ小、岸際|
|サヨリ|海辺・海の小島|オキアミ、ハリ小、岸際|
|マサバ|海辺・海の小島|オキアミ、ハリ中、中層〜深場|

山側4地域に4軒の民家と2か所のサムの売店を追加。売店は既存の商品・数量・価格・購入処理を共有する。扉へ向いてAで入り、退出時は同じ位置へ戻る。建物の壁は通行不可。元の地形原画は変更しない。

村と山側各地の計11人の住人が短い散歩をする。近くでは止まり、衝突判定・ゲーム内乱数・時間・所持品を消費しない。夜・メニュー中・画面非表示中は動かない。民家では場所・雨・夜に応じた短い会話を表示する。

峠の池の全周を描かれた岸道へ合わせ直した。村・小島の岸歩行では障害物の手前まで安全な部分歩行を許す。水、壁、木の根、舟の既存判定は保持。主人公宅へは村につながる庭の右側から着き、同じ右道から村へ戻る。

村の季節色を建物・小物の矩形レイヤーから独立させ、同じ画素を同じ色へ変換する。淡い緑の波打ち際を紅葉にしない。キャスト背景は近岸を残す位置へ揃え、港は上部の岸壁へ合わせる。全12ポーズで両足の接地点を固定する。

画材8点は内蔵画像生成の新規生成モードで作成。透過PNG原本を変更せず、実行時に測定した輪郭範囲を切り出す。ファイル名と全プロンプトは `v238-art-prompts.json`、寸法・SHA-256は `v238-art-manifest.json`、魚の切り出し範囲は `fish-art-v238.json` に保存。

確認は `living-waters-v238.test.cjs` と `browser-v238.life.cjs` を参照。ChromiumのPC 1280×720、タッチ844×390、820×366／DPR 1.875で移動キー・A・商品購入・仕掛け選択を操作する。釣果検証は通常抽選内の乱数と待ち時間のみ固定し、釣獲数を直接増やさない。物理スマートフォンでの実機検証ではない。
