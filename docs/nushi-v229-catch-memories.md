# v229: 初釣果と自己最大の思い出

図鑑の既知の魚に「釣りの思い出」を追加した。折りたたみを開くと、はじめての一匹と現在の最大記録の一匹を並べて振り返れる。

- サイズとサイズ帯、釣り場、ゲーム内日時と季節、天気、竿、餌／ルアー、実際に使ったハリ、ファイト方式、同行犬を保存する。
- 最初の釣果は上書きしない。最大記録は既存のサイズ記録が更新されたときだけ置換し、同サイズでは以前の記録を保つ。
- 日時・天気・犬は投げて資源を消費した際に固定する。一投10分を進めた後の釣り場の時計を使い、日付境界と大会の釣り場時計にも対応する。
- 古いセーブの釣果や最大記録を保つ。以前の初釣果の日時は推測しない。現在の最大記録を超えるまで、その一匹の詳しい記録は未記録と表示する。
- 練習・失敗では記録を増やさない。ルアーの記録に使っていない餌やハリを表示しない。未発見の魚には思い出欄を出さない。
- 一種につき二つの記録なので、釣果回数に比例して保存量を増やさない。二つのセーブの記録を分け、図鑑を読むだけでは時間・体力・所持品を消費しない。
- 新しいJS／CSSとService Workerの版を229-1にした。v228の釣りの入力猶予・魚の強さ・装備の数値は変更しない。

## 検証

実装時の専用テスト8件が成功した。初釣果維持、最大更新・同サイズ・小さい個体、旧セーブ、投げた際の時計と日付境界、ルアー、練習と失敗、不正な保存値、再読み込み、二つのセーブ、閲覧時の資源維持を検証した。

既存の自然な釣り上げ8ケースにも、新しい思い出・仕掛け・保存・再読み込みの検査を追加した。PCと844×390のタッチで思い出欄を開き、文字の折り返し、未知の魚の非表示、キーボードでの開閉を確認するブラウザ検査を追加した。

この文書の初版時点では、全体CIとブラウザの表示検証・公開検証は未完了。完成した検証結果は作業完了後に追記する。
