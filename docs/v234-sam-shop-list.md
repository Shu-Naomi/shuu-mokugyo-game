# v234: サムの候補一覧と会話で買い物する

v233のお店は候補と大きな説明枠に分かれ、スマホ横持ちでは餌6種類が2種類ずつに分割されていた。サムの全売り場を一つの候補一覧にし、選んだ品の説明をサムの既存メッセージボックスに表示する。

- 余裕のある画面では縦の一覧、短い横持ちでは2列に切り替える。対象のスマホ2サイズで餌6種類を同時に表示する。
- 購入操作は候補のすぐ下に置き、餌の個数選びも同じ一列にまとめる。ルアーなど1種類しかない売り場でも説明用の大きな空枠を作らない。
- 候補をタップするだけでは購入せず、所持金・持ち物・時間・セーブを変更しない。元の購入ボタンと数量ボタンを移動して使い、価格・個数・所持判定・保存処理を保持する。
- 説明は既存の `setSamShopDialogue` / `setDialogue` を通し、文字送り・案内・購入結果の会話を保持する。画面の高さが変わったときは選択を維持し、購入結果を説明文で上書きしない。
- 水槽、他のお店、道具袋のレイアウトはこの変更の対象外。

確認対象は、全6種類の表示、説明と購入操作の一致、数量変更と選択の維持、実際の支払いと加算、保存と再読み込み、既存の買い物・料理・装備・水槽操作。
