# v233 — ぬし釣り64を参考にしたお店・道具袋

1998年版『ぬし釣り64』取扱説明書の10–11頁「命令ウィンドウ」、12–13頁「道具の使い方」、16頁「村の案内」を視覚確認した。参考元は小さな緑の枠、三角カーソル、短い選択肢、村の店と会話の構成。現在のゲームにはアイコンとタッチ用44pxの操作を足し、原作の画面をそのまま再現する変更とはしていない。

資料: https://gamemanual.midnightmeattrain.com/entry/%E3%81%AC%E3%81%97%E9%87%A3%E3%82%8A64

- サム・八百屋・食堂: 店内を約40%に広げ、会話を店内の下に常時表示。棚を44pxの一覧にし、選択した一品の絵・説明・元の操作ボタンを横に表示。
- 舟具屋・アスアル・持ち物・装備・タックル: 同じ一覧と選択ペインを使用。一ページで収まる分類にはページ送りを表示しない。
- 品物選択と方向キーは表示状態だけを変える。購入・食べる・装備・調理は元のボタンと処理を保持。数量、価格、保存形式、育成・繁殖ルールを変更しない。
- 長い補足は「詳しく」、大会・イベント・使い方は「案内」から従来の処理を利用。

検証: 既存の売買・共有在庫・調理・重複竿・保存のテストに、選択・方向キーが売買や保存を行わないこと、一品の棚のページ送りが隠れることを追加。1280×720、844×390、820×366の実ブラウザー検証も行う。
