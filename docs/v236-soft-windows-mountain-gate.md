# v236 — 丸いウィンドウと峠の池の山道

峠の池から峠の沼へ続く北東の山道は、絵の折り返しに対して通行判定が崖側へ直線的に伸びていた。通行経路を既存のドット絵に沿って引き直し、その枝道だけ幅を調整した。沼から戻る座標も崖の上から道の上（212,10）へ移した。背景画像・魚の出現条件・価格・釣りや購入の処理は既存のものを使う。

旧セーブが以前の帰還座標にある場合は、既存の位置補正で近くの歩ける地面へ戻る。魚・所持金・餌の保持と移動再開を確認する。

ショップ・持ち物のウィンドウ、商品選択、タブ、会話欄、会計札の角を丸くした。画面の配置・文字サイズ・44pxの操作領域は維持した。

検証はタッチ矢印で折り返しを順番に歩き、峠の池→峠の沼→水郷の湿地→帰還を行う。湿地の三種類の水辺で通常の釣り場判定、資源の保持、帰還後のセーブ再開を確認する。既存のショップ・水槽のスマホ横画面チェックも行う。
