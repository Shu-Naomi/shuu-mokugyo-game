# v237 — 峠の沼の道と魚の配置

峠の沼の古い水域・通行経路は、完成した背景の道から外れていた。入口も道の左側にあり、七か所の木橋・木の足場が橋として登録されていなかった。背景はそのままに、240×135の世界座標で道、水際、木の床を引き直した。沼の外周を一周でき、木橋を渡り、東西南北の岸で釣れるようにした。入口を (48,128)、湿地から戻る地点を (227,78) の道の上へ移した。古いセーブは既存の位置補正で近くの地面へ戻る。

峠の沼は「葦の沼」の出現表をそのまま使っていた。独立した出現表に変更し、実装済みのタナゴ・モツゴ・メダカ・ライギョを配置した。ドジョウを含む従来の魚も残る。魚種数は39種のままで、魚の性能、餌・ハリ、釣りの処理、図鑑番号、ぬしの解放条件は変えない。

| 狙う魚 | 水深 | 既存の仕掛けの目安 |
| --- | --- | --- |
| タナゴ | 岸際〜中層 | 練りエサ＋ハリ小 |
| モツゴ | 岸際〜中層 | 川虫＋ハリ小 |
| メダカ | 岸際 | 川虫＋ハリ小 |
| ライギョ | 中層〜深場 | 活き小魚＋ハリ大 |
| ドジョウ | 岸際〜深場 | ミミズ＋ハリ小 |

図鑑の釣り場所と岸辺の操作案内も出現表に合わせた。カマツカは水郷の湿地の砂底の小川、ニゴイはその小川・葦の沼に引き続き配置される。

検証では背景から独立に測った道と木橋の点をタッチ矢印で順に巡り、四方向の岸、峠の池・水郷の湿地との往復、資源の保持、セーブ再開を確認する。通常の仕掛けと出現表で五種を抽選し、投げる・アタリ・フッキング、描画、餌の消費、重複捕獲防止、釣果の保存を確認する。抽選とアタリのタイミングはテスト内で固定し、製品コードの釣り処理を使う。スマホ横画面844×390、820×366とPC1280×720で実画面を保存する。
